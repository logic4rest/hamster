## 📜 1. AI 지시 핵심 프롬프트 (복사하여 사용)

아래 프롬프트를 AI 어시스턴트 입력창에 복사해서 붙여넣으시면, AI가 이 프로젝트의 규격을 100% 준수하면서 프로그램을 개발해 줍니다:

```text
[요청]
햄스터 로봇 AI 스마트 쓰레기 분리배출 시스템 개발을 진행하려 합니다.
아래 핵심 규격과 개발 규칙을 반드시 준수하여 파이썬 코드 및 웹 관제 시스템을 작성해 주세요.

[핵심 시스템 규격]
1. AI 카메라 인식 신뢰도 기준: CONFIDENCE_THRESHOLD = 0.8 (80% 미만은 대기/없음 처리)
2. 연속 프레임 확정 알고리즘: REQUIRED_FRAMES = 6 (동일 쓰레기가 연속 6프레임 감지되면 수거 시작)
3. 수거 동작 시퀀스:
   - 6프레임 분석 완료 시 "삐!" 알림음 발성.
   - 바로 주행하지 않고, 제자리에 멈춰 집게를 열고(OPEN) 4초간 거치 대기 (WAIT_PLACEMENT_SEC = 4.0).
   - 4초 카운트다운 완료 후 집게를 닫고(CLOSE) 지정 수거함 슬롯(1~4번)으로 자율주행.
   - 수거함 도착 시 집게를 열어 쓰레기 투입 후 1:1 대칭 역주행 궤적 엔진으로 시작 위치 오차 0.00cm 정밀 복귀!
4. LED 제어 규격:
   - 플라스틱/페트병: 파란색 LED (blue)
   - 캔: 초록색 LED (green)
   - 종이: 노란색 LED (yellow)
   - 종이팩: 하늘색/흰색 LED (white)
   - 경고/이물질: 빨간색 LED (red)
5. 스마트폰 QR 관제 웹서버:
   - Flask 기반 5000번 포트 웹서버 백그라운드 구동.
   - HTML5 Canvas 2D 시뮬레이터 ↔ 실제 로봇 듀얼 모드 제공.
   - 소스코드 전체 ZIP 압축 다운로드 기능 (/download) 구현.
```

## 💡 2. 자주 쓰는 AI 개발 팁 (Q&A)

### Q. 새로운 쓰레기 카테고리(예: 유리병)를 추가하고 싶어요.
AI에게 다음 프롬프트를 전달하세요:
> "CATEGORY_MAP과 LED_MAP에 '유리병' 카테고리를 추가해 줘. LED는 보라색(magenta)으로 점등하고, 수거함 5번 슬롯 위치를 등록할 수 있게 해줘."

### Q. 카메라 없이 웹 브라우저에서만 시뮬레이션하고 싶어요.
AI에게 다음 프롬프트를 전달하세요:
> "OpenCV 카메라가 없을 때 HTML5 Canvas 2D 가상 아레나 시뮬레이터 모드로 자동으로 전환되도록 fallback 예외 처리를 구현해 줘."

## 🎨 3. 햄스터 로봇 쓰레기 5종 제어표

| 쓰레기 범주 | 확정 조건 | 로봇 알림 반응 | LED 표시 색상 |
| :--- | :---: | :---: | :---: |
| **플라스틱 / 페트병** | 연속 6프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 4초 대기 + 2초 점등 | **파란색 LED** 🔵 (`blue`) |
| **캔** | 연속 6프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 4초 대기 + 2초 점등 | **초록색 LED** 🟢 (`green`) |
| **종이** | 연속 6프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 4초 대기 + 2초 점등 | **노란색 LED** 🟡 (`yellow`) |
| **종이팩 (우유팩)** | 연속 6프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 4초 대기 + 2초 점등 | **하늘색/흰색 LED** ⚪ (`white`) |
| **대기 / 미인식** | 신뢰도 < 0.8 | 대기 유지 | **LED OFF** ⚪ (`off`) |

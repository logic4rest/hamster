# 🐹 햄스터 로봇 AI 스마트 분리배출 자율주행 시스템 (v3.8 통합 마스터 에디션)

웹캠 카메라를 통해 **쓰레기(플라스틱, 캔, 종이, 종이팩)** 및 **경고 품목(유리병, 이물질)**을 실시간으로 감지하고, **사용자가 화살표 키로 조종하여 엔터로 기억시킨 위치(routes/paper_route.json)**로 이동하며, **전방 적외선 센서로 장애물 발견 시 자동으로 우회 회피 주행**하여 실물 집게로 쓰레기를 분리수거하는 통합 AI 로봇 시스템입니다.

---

## ✨ 핵심 기능 3대 통합 완성

1. **🎮 화살표 키 조종 & 엔터(Enter) 위치 기억 (Teach & Record)**:
   - 햄스터를 시작 위치에 두고 **화살표 키(`↑`, `↓`, `←`, `→`)**로 실제 종이 분리수거함 위치까지 직접 운전합니다.
   - 종이 수거함에 도착했을 때 **`Enter (엔터)`**를 누르면, 그동안의 모든 주행 경로와 회전 시간이 완벽하게 기억(저장)됩니다!

2. **🤖 카메라 종이 확인 시 기억된 위치로 자율 이동 (Autonomous Replay)**:
   - 카메라에 **종이**를 비춰주면, 실물 집게로 종이를 포획(`close_gripper()`)한 후 **방금 기억시킨 그 경로 그대로 종이 수거함까지 자율 이동**하여 배출합니다.

3. **⚠️ 전방 적외선 센서 장애물 감지 & 지능형 자동 우회 주행 (Smart Obstacle Detour)**:
   - 로봇이 이동하는 도중 앞쪽에 상자, 손, 물건 등 **장애물이 나타나면 전방 센서(`left_proximity`, `right_proximity`)가 즉시 감지**합니다.
   - 삐! 소리와 함께 **장애물을 옆으로 슥 비켜서 돌아간(우회한) 후**, 원래 목표인 종이 수거함까지 끝까지 찾아갑니다!

## 🚀 빠른 시작 가이드

### 1단계: 화살표 키로 종이 위치 조종하고 엔터로 기억시키기
```bash
uv run python tools/record_paper_path.py
```
1. 햄스터를 카메라 시작 위치에 놓습니다.
2. 키보드 **화살표 키(`↑`, `↓`, `←`, `→`)**로 종이 수거함까지 운전합니다.
3. 도착하면 **`Enter (엔터)`** 키를 누릅니다. (삐! 소리와 함께 저장 후 시작 위치로 자동 복귀)

---

### 2단계: AI 스마트 감지 & 전방 장애물 우회 자율주행 실행
```bash
uv run python main.py
```
- 카메라에 **종이**를 비추면:
  1. 집게로 종이를 잡습니다 (`close_gripper()`).
  2. **방금 엔터 쳐서 기억시킨 위치로 로봇이 알아서 이동**합니다.
  3. **이동 중간에 물건을 놓아두면, 전방 센서로 알아서 슥 피해서(우회해서)** 종이 수거함까지 안전하게 찾아갑니다!
  4. 종이를 넣고 (`release_gripper()`), 다시 원래 자리로 복귀합니다.

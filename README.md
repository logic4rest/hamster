# 🐹 햄스터 로봇 AI 쓰레기 분리배출 스마트 감지 시스템

웹캠 카메라를 통해 **쓰레기 5종 (플라스틱/페트병, 캔, 종이, 유리병, 종이팩)**을 실시간으로 감지하고, [Google 티처블 머신](https://teachablemachine.withgoogle.com) 모델과 **햄스터 로봇**의 5색 LED 및 부저 알림을 이용하여 분리배출을 안내하는 파이썬 프로그램입니다.

---

## ✨ 핵심 시스템 기능

1. **연속 4프레임 필터링 (안정적 확정 알고리즘)**
   - 오인식과 실시간 반응성의 균형을 위해 동일 쓰레기 범주가 **연속 4프레임** 동안 감지되었을 때 최종 배출 대상으로 확정합니다.
2. **신뢰도 기준 80% (`CONFIDENCE_THRESHOLD = 0.8`)**
   - 모델 인식 신뢰도가 0.8 미만인 경우 안전하게 대기(미인식) 상태로 처리합니다.
3. **바운딩 박스(Bounding Box) 오버레이**
   - 카메라 화면 중앙에 객체 포획 사각형과 카테고리 태그(`[확정] 플라스틱/페트병` / `종이 | 95% [1/4]`)가 실시간으로 렌더링됩니다.
4. **시각 및 청각 피드백**
   - 최종 확정 시 햄스터 로봇에서 **삐(Beep) 소리**가 나며, 카테고리별 지정 **LED가 2초 동안 점등**되어 사용자에게 배출을 안내합니다.

## 📂 디렉터리 구조

```text
hamster/
├── README.md               ← 프로젝트 안내서 (현재 파일)
├── AGENTS.md               ← 개발 및 트러블슈팅 가이드
├── pyproject.toml          ← 프로젝트 메타데이터 & 의존성

├── hamster/
│   ├── __init__.py
│   └── __main__.py         ← 패키지 진입점 (roboidai 방식, 권장)
├── models/
│   ├── keras_model.h5      ← 티처블 머신 Keras 모델

├── data/                   ← 쓰레기 종류별 수집 이미지 데이터셋 (7개 폴더)

    ├── check_connection.py     ← 햄스터 연결 & 하드웨어 점검 도구
```

## 🚀 빠른 시작

**uv 사용 (권장)**

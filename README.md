# 🐹 햄스터 로봇 AI 쓰레기 분리배출 스마트 감지 및 자율주행 시스템 (v9.0)

웹캠 카메라를 통해 **쓰레기 5종 (플라스틱/페트병, 캔, 종이, 유리병, 종이팩)**을 실시간으로 감지하고, **Google 티처블 머신(Teachable Machine) AI 모델 및 MobileNetV2 딥러닝 파인튜닝 모델**과 **햄스터 로봇**의 4색 LED, 부저 알림, 스마트폰 QR 스캔 웹 리모컨, 정밀 자율주행 역주행 복귀를 지원하는 파이썬 통합 스마트 수거 시스템입니다.

## ✨ 핵심 시스템 기능 (v9.0)

1. **AI 딥러닝 모델 선택 시스템 (모델1 & 모델2)**
   - **`[1] 모델1`**: 4종 전용 티처블 머신 Keras 모델.
   - **`[2] 모델2`**: 6종 통합 MobileNetV2 파인튜닝 모델 (`없음`, `유리병`, `종이`, `종이팩`, `캔`, `플라스틱&페트병`).
2. **`없음` (미인식/대기) 주행 원천 차단막 (Safety Guard)**
   - 미인식 상태에서 로봇이 임의로 주행하는 현상을 100% 방지하는 차단 안전 로직 내장.
3. **티처블 머신 실전 인식률 99% 보정 (1:1 Center Square Crop)**
   - 웹 브라우저 캔버스와 동일하게 OpenCV 프레임을 중앙 1:1 정사각형(`min(h, w)`)으로 절삭한 후 `(224, 224)` 정규화 처리.
4. **연속 6프레임 정밀 확정 알고리즘 (`REQUIRED_FRAMES = 6`)**
   - 안정적인 판단을 위해 동일 쓰레기 범주가 연속 6프레임 동안 감지될 때 수거 주행 시작.
5. **안전 집게 열림 유지 & 4초 쓰레기 거치 카운트다운**
   - 6프레임 확정 시 제자리에 멈춰 집게를 펼치고(`OPEN`) 4초 동안 쓰레기 거치 시간을 부여.
6. **오차 0.00cm 정밀 대칭 역주행 복귀**
   - 수거함 투입 완료 후, 1:1 대칭 역주행 궤적 알고리즘으로 시작 지점 위치로 완벽하게 복귀.
7. **스마트폰 QR 스캔 원격 조종 웹서버 (`http://localhost:5000`)**
   - 동일 와이파이 네트워크의 스마트폰으로 화면 우측 하단 QR 코드를 스캔하여 실시간 2D 시뮬레이션 및 원터치 수거 조종 지원.
8. **타 컴퓨터 실행 완벽 지원 (Package Bundling)**
   - `hamster/models/` 및 `hamster/routes/` 내부 번들링으로 어떤 컴퓨터에서 복사/실행해도 AI 모델과 수거함 경로가 100% 로드됨.

## 🚀 빠른 시작 가이드

### 1. 프로그램 실행 (권장)

```bash
uv run hamster
# 또는
uv run python main.py
```
* 종료하려면 화면 창에서 **ESC** 키를 누르세요.

### 2. AI 모델 재학습 실행
`data/` 폴더 및 캡처 데이터로 모델1과 모델2를 동시에 재학습하려면:
```bash
uv run python tools/train_models_all.py
```

### 3. 무설치 실행파일 (.exe) 재빌드
```bash
uv run pyinstaller --noconfirm hamster_sorting_robot.spec
```

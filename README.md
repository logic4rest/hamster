## ✨ 핵심 시스템 6대 통합 기능

1. **⚡ 100% 인터넷 독립 오프라인 웹앱 (PWA)**:
   - 랜선이나 Wi-Fi를 끄더라도 **컴퓨터와 스마트폰에서 100% 오프라인 독립 작동**합니다.
   - 안드로이드(Android) & 아이폰/아이패드(Apple iOS) 손가락 터치 시 **실제 스마트폰 진동(Haptic) 피드백**을 제공합니다.

2. **🤖 연속 6프레임 분석 (`REQUIRED_FRAMES = 6`) & 4초 거치 대기 시퀀스**:
   - 동일 쓰레기가 연속 6프레임 동안 감지되면 "삐!" 소리와 함께 **제자리에 멈춰 집게를 열고(`OPEN`) 4초간 쓰레기 놓기 대기**합니다.
   - 4초 카운트다운 후 **집게를 닫아(`CLOSE`) 쓰레기를 포획**하고 지정 수거함으로 주행합니다.

3. **↩️ 1:1 정밀 물리 대칭 역주행 복귀 엔진 (오차 0.00cm PASS)**:
   - 수거함에 쓰레기를 배출한 후, 왕복 주행 오차 없이 **출발 지점(0,0)으로 0.00cm 오차 없이 완벽하게 역주행 복귀**합니다.

4. **🎮 2D 가상 아레나 시뮬레이터 ↔ 1:1 실물 햄스터봇 듀얼 모드**:
   - 실물 로봇이 없어도 **웹 브라우저 2D 캔버스 아레나에서 가상 햄스터봇 동작을 100% 자율 검증**할 수 있습니다.

5. **📦 Windows 전용 독립 실행 파일 (.exe) 빌드 지원**:
   - 파이썬이 설치되지 않은 PC에서도 `햄스터_분리배출_실행파일.bat` 또는 `dist/hamster_sorting_robot/hamster_sorting_robot.exe` 더블클릭으로 1초 만에 실행됩니다.

6. **📁 개발자/사용자용 `제작/` 가이드 패키지 내장**:
   - 누구나 새 로봇 프로젝트를 쉽게 만들 수 있도록 스타터 코드(`starter_template.py`), AI 어시스턴트 지시 프롬프트(`AI_PROMPTS_AND_RULES.md`), 빌더 스크립트가 내장되어 있습니다.

## 🚀 빠른 시작 가이드

### 1단계: 의존성 설치 및 실행
```bash
# uv 사용 시 (권장)
uv sync
uv run python main.py

# 또는 바탕화면의 [햄스터_분리배출_실행.bat] 더블클릭
```

### 2단계: PyInstaller 독립 실행 파일 (.exe) 빌드
```bash
uv run pyinstaller hamster_sorting_robot.spec
# 생성 위치: dist/hamster_sorting_robot/hamster_sorting_robot.exe
```

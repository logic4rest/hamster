# 🐹 햄스터 로봇 AI 쓰레기 분리배출 스마트 감지 시스템 (v2.6)

웹캠 카메라를 통해 **쓰레기(플라스틱/페트병, 캔, 종이, 종이팩)** 및 **경고 품목(유리병, 이물질/라벨/음식물)**을 실시간으로 감지하고, [Google 티처블 머신](https://teachablemachine.withgoogle.com) 모델과 **햄스터 로봇**의 6색 LED 및 부저 알림을 이용하여 분리배출을 안내하는 파이썬 프로그램입니다.

---

## 🎨 쓰레기 분리배출 & 경고 LED 안내표

| 쓰레기 범주 | 감지 대상 | 확정 조건 | 로봇 알림 반응 | LED 표시 색상 |
| :--- | :--- | :---: | :---: | :---: |
| **플라스틱 / 페트병** | `무색 페트병, 무색플라스틱` (깨끗함) | 연속 4프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 2초 LED | **파란색 LED** 🔵 (`blue`) |
| **유리병 (경고)** | `유리병, 유리통` | 연속 4프레임 (신뢰도 ≥ 0.8) | **삐 소리 + 2초 LED (유리 수거함 자막)** | **주황색 LED** 🟠 (`Orange RGB`) |
| **캔** | `캔` | 연속 4프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 2초 점등 | **초록색 LED** 🟢 (`green`) |
| **종이** | `종이` | 연속 4프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 2초 점등 | **노란색 LED** 🟡 (`yellow`) |
| **종이팩 (우유팩)** | `종이팩` | 연속 4프레임 (신뢰도 ≥ 0.8) | 삐 소리 + 2초 점등 | **하늘색 LED** 🩵 (`cyan`) |
| **이물질 (경고)** | `라벨 미제거`, `음식물`, `얼음` | 연속 4프레임 (신뢰도 ≥ 0.8) | **경고 삐 소리 + 2초 점등** | **빨간색 경고 LED** 🔴 (`red`) |
| **대기 / 미인식** | `없음` 또는 신뢰도 미달 | 신뢰도 < 0.8 | 대기 유지 | **LED OFF** ⚪ (`off`) |

## ✨ 핵심 스마트 기능 (v2.6)

1. **🟠 유리병 전용 주황색 LED & 개별 안내 수칙**
   - 유리병/유리통 감지 시 **주황색 LED(🟠)**가 점등되며, *"⚠️ 경고: 유리는 플라스틱 통이 아닌 전용 유리 수거함에 따로 담아주세요!"* 자막이 표시됩니다.
2. **⚠️ 페트병 내 이물질/라벨 감지 경고 시스템**
   - 페트병 안에 음식물/얼음이 들어있거나 라벨이 떼어지지 않은 경우 **빨간색 경고 LED(🔴)**와 경고음으로 세척 및 라벨 제거 안내를 유도합니다.
3. **📸 감지 순간 자동 캡처 (`captures/`)**
   - 연속 4프레임 확정이 일어나는 순간의 카메라 화면을 `captures/YYYYMMDD_HHMMSS_카테고리.jpg` 경로로 자동 저장합니다.
4. **💡 실시간 올바른 분리배출 꿀팁 자막 표시**
   - 화면 하단에 각 쓰레기별 올바른 분리배출 안내 수칙(예: *"라벨을 떼고 찌그러뜨려 버려주세요!"*)이 한글 자막으로 실시간 렌더링됩니다.
5. **📊 실시간 수거 통계 HUD & 누적 저장 (`stats.json`)**
   - 화면 상단에 실시간 수거 총량 및 쓰레기종별 개수 통계를 HUD로 표시하고 `stats.json` 파일에 자동 누적 기록합니다.

```text
hamster/

    ├── check_connection.py     ← 햄스터 연결 & 하드웨어 점검 도구
    ├── keyboard_control.py    ← 키보드 방향키/WASD 실시간 조종 도구
    └── generate_yolo_dataset.py ← YOLO 학습용 데이터셋 자동 생성 도구
```

## 🚀 빠른 시작

### 1. 의존성 설치

**uv 사용 (권장)**
```bash
uv sync
```

### 2. 스마트 분리배출 프로그램 실행

```bash
cd hamster
uv run python main.py
# 또는
uv run hamster
```

* 종료하려면 카메라 창에서 **ESC** 키를 누르세요.

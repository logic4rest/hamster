# 16차시 — 손모양 인식 (티처블 머신)

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 246–269쪽

웹캠으로 가위/바위/보 손모양 이미지를 수집하고, 구글 **티처블 머신**으로 이미지 분류 모델을 학습시킨 뒤, 파이썬(`roboidai`)에서 그 모델로 실시간 손모양을 인식해 햄스터 로봇을 제어하는 실습이다.

**준비물**
- USB 웹캠, 햄스터 로봇 + BLE 동글
- 라이브러리 설치: `pip install -U roboidai mediapipe`
- 티처블 머신: https://teachablemachine.withgoogle.com

---

## 01 영상 수집 (247–249p)

### 클래스·메소드 안내

| 메소드 | 설명 |
|---|---|
| `collect_image(cam, folder)` | 카메라를 사용하여 **스페이스 키를 누를 때마다** 영상을 촬영하여 저장한다. ESC 키를 누르면 종료한다. |
| `record_image(cam, folder, interval_msec=100, frames=20, countdown=3)` | 카메라를 사용하여 카운트다운 후에 `interval_msec` 간격으로 `frames`개의 영상을 촬영하여 저장한다. ESC 키를 누르면 종료한다. |

파라미터:

| 파라미터 | 설명 |
|---|---|
| `cam` | 카메라 객체 |
| `folder` | 영상을 저장할 폴더. 폴더가 존재하지 않으면 생성함 |
| `interval_msec` | 영상을 저장하는 시간 간격 (msec) |
| `frames` | 저장할 영상 개수 |
| `countdown` | 카운트다운 수 |

### 예제 1 — 스페이스 키를 누를 때마다 사진 저장

```python
import roboidai as ai
import roboidai.lab.ko as lab

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 화면
lab.collect_image(cam, 'c:/Example/scissors')
```

### 예제 2 — 200msec(0.2초) 간격으로 30개 영상 촬영·저장

```python
import roboidai as ai
import roboidai.lab.ko as lab

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 화면
lab.record_image(cam, 'c:/Example/scissors', 200, 30)
```

같은 방법으로 클래스별 폴더에 나누어 수집한다:

- `c:/Example/scissors` — 가위
- `c:/Example/rock` — 바위
- `c:/Example/paper` — 보

## 02 영상 학습 (250–263p)

티처블 머신 웹사이트에서 수집한 이미지로 모델을 학습시키고 Keras 형식으로 내려받는다.

1. **teachablemachine.withgoogle.com**에 접속한다. → `Get Started` 클릭
2. **Image Project**를 클릭한다. (표준 이미지 모델)
3. **Class 1**을 클릭해 클래스 이름을 **'가위'** 로 변경한다.
4. **Upload** → **Choose images from your files**를 클릭한다.
5. 영상을 저장한 폴더에서 가위 영상을 모두 선택하고 **열기**를 클릭한다.
6. **Class 2와 Class 3**도 마찬가지로 **'바위'**, **'보'** 사진을 업로드한다.
7. 사진을 모두 업로드했으면 **Train Model**을 클릭한다.
8. 학습이 완료되면 **Export Model**을 클릭한다.
9. **Tensorflow** 탭을 클릭한다.
10. **Keras**를 선택한 후 **Download my model**을 클릭한다. (변환은 클라우드에서 진행되며, 학습 데이터가 아닌 학습된 모델만 업로드된다)
11. 변환이 끝나면 `converted_keras.zip` 파일이 다운로드된다.
12. 다운로드된 `converted_keras.zip`을 적절한 위치에서 압축을 풀어 준다. 예) `c:/Example/가위바위보`

압축 파일 내에는 2개의 파일이 들어 있다:

- `keras_model.h5` — 학습된 Keras 모델
- `labels.txt` — 클래스 레이블 목록

## 03 가위바위보 실습 (264–269p)

### TmImage 클래스·메소드 안내

| 메소드 | 설명 | 반환 값 |
|---|---|---|
| `predict(image, threshold=0.5)` | 영상을 인식한다. `image`: 인식할 입력 영상(numpy.ndarray), `threshold`: 신뢰도가 threshold 이상인 경우에만 인식된 것으로 인정 | `True`: 인식 성공, `False`: 실패 |
| `get_label()` | 인식 결과의 레이블을 반환한다 | 신뢰도 값이 가장 큰 클래스의 레이블 |
| `get_conf()` | 인식 결과의 신뢰도를 반환한다 | 신뢰도 값이 가장 큰 클래스의 신뢰도 |
| `get_all_labels()` | 모든 클래스의 레이블 목록을 반환한다 | 모든 클래스의 레이블 목록 (numpy.ndarray) |
| `get_all_confs()` | 모든 클래스의 신뢰도 목록을 반환한다 | 모든 클래스의 신뢰도 목록 (numpy.ndarray) |

### 예제 1 — 학습한 모델로 분류하기 (266p)

```python
import roboidai as ai

tmi = ai.TmImage()
tmi.load_model('c:/Example/가위바위보')

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 이미지
cam.count_down(3)

while True:
    image = cam.read()
    if tmi.predict(image):  # 인식 성공 시
        label = tmi.get_label()  # 인식한 결과를 반환합니다.
        print(label)  # 인식한 결과를 출력합니다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

### 예제 2 — 신뢰도가 일정 값 이상인 경우에만 결과 출력 (267p)

```python
import roboidai as ai

tmi = ai.TmImage()
tmi.load_model('c:/Example/가위바위보')

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 이미지
cam.count_down(3)

while True:
    image = cam.read()
    if tmi.predict(image):  # 인식 성공 시
        label = tmi.get_label()  # 인식한 결과를 반환합니다.

        conf = tmi.get_conf()  # 신뢰도를 반환합니다.
        if conf > 0.8:
            print(label, conf)  # 인식한 결과와 신뢰도를 출력합니다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

### 예제 3 — 인식 결과로 햄스터 움직이기 (268p)

가위 = 전진, 바위 = 후진, 보 = 정지.

```python
import roboidai as ai

tmi = ai.TmImage()
tmi.load_model('c:/Example/가위바위보')

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 이미지
cam.count_down(3)

while True:
    image = cam.read()
    if tmi.detect(image):  # 인식 성공 시
        label = tmi.get_label()  # 인식한 결과를 반환합니다.
        conf = tmi.get_conf()  # 신뢰도를 반환합니다.
        if conf > 0.8:
            print(label, conf)  # 인식한 결과와 신뢰도를 출력합니다.

                hamster.wheels(30, 30)
            elif label == '바위':
                hamster.wheels(-30, -30)

```

### 예제 4 — `.predict()`의 threshold 매개변수 활용 (269p)

신뢰도 비교 `if conf > 0.8:`을 없애고, 인식 메소드의 두 번째 매개변수로 신뢰도 기준을 바로 지정한 버전.

```python
import roboidai as ai

tmi = ai.TmImage()
tmi.load_model('c:/Example/가위바위보')

cam = ai.Camera('usb0', flip='h', square=True)  # USB 카메라를 사용한다(웹캠). 수평 반전, 정사각형 이미지
cam.count_down(3)

while True:
    image = cam.read()
    if tmi.detect(image, 0.8):  # 인식 성공 시. 신뢰도가 0.8 이상일 때만 인식 인정
        label = tmi.get_label()  # 인식한 결과를 반환합니다.
        conf = tmi.get_conf()  # 신뢰도를 반환합니다.

        if label == '가위':
            hamster.wheels(30, 30)
        elif label == '바위':
            hamster.wheels(-30, -30)
        elif label == '보':
            hamster.stop()

    cam.show(image)
    if cam.check_key() == 'esc': break
```

### 교재 원문 관련 유의점

- 교재 268–269p 코드는 `tmi.detect(...)`를 사용하지만, 264p API 표에는 `predict(image, threshold=0.5)`로 안내되어 있다(명칭 불일치). 위 코드는 교재 슬라이드 원문 그대로 옮긴 것이며, 실행 시 오류가 나면 `detect`를 `predict`로 바꿔 시도한다.
- 예제 3·4의 햄스터 구동 코드에는 `hamster` 객체 생성이 생략되어 있다. 실제 실행하려면 상단에 다음을 추가해야 한다:

  ```python
  from roboid import *
  hamster = Hamster()
  ```

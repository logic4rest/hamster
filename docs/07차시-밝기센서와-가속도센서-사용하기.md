# 7차시 — 밝기센서와 가속도센서 사용하기

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 104–115쪽

밝기 센서로 어둠을 감지해 소리를 내고, 3축 가속도 센서로 충격·기울어짐을 감지해 넘어짐 감지·시소놀이 등을 만든다.

---

## 01 어둠이 무서워요 (105–107p)

햄스터 로봇의 앞면에는 근접 센서의 광 트랜지스터와 같은 위치에 빛의 밝기를 감지하는 밝기 센서가 있다. 밝기 센서는 0부터 65535 Lux까지의 값을 가지며, 밝을수록 값이 커진다.

코드를 작성하기 전에 우선 밝기 센서의 값을 관찰해본다. 밝기 센서를 손으로 가리거나 모니터 화면 또는 형광등과 같이 밝은 곳을 향했을 때 센서 값이 어떻게 달라지는지 관찰한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    print(hamster.light())
    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

**옷이나 종이 박스로 덮으면 버저 소리 내기**
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.light() < 10:
        hamster.buzzer(1000)
    else:
        hamster.buzzer(0)

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

**어두울수록 높은 음 내기** — 밝기 센서 값이 100일 때 버저 음의 높이는 100, 밝기 센서 값이 5일 때 버저 음의 높이는 2000이 되도록 하고, 그 사이를 일정 비율로 버저 음이 높아지도록 하면 `(버저 음) = 2100 - (밝기) * 20`이 된다.
```python
from roboid import *

hamster = HamsterS()

while True:
    value = hamster.light()
    print(value)

    if value < 5:
        hamster.buzzer(2000)
    elif value > 100:
        hamster.buzzer(0)
    else:
        hamster.buzzer(2100 - value * 20)

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

## 02 빛으로 말해요 (2인 1조) (108–110p)

모스 부호를 만들어 햄스터 친구에게 전달한다.

**첫 번째 햄스터 로봇** — 하얀색 LED를 짧게 또는 길게 깜빡여서 모스 부호를 표현한다.
```python
from roboid import *

hamster = HamsterS()

def blink_short():
    hamster.leds(hamster.COLOR_NAME_WHITE)
    wait(200)
    hamster.leds(0)
    wait(200)

def blink_long():
    hamster.leds(hamster.COLOR_NAME_WHITE)
    wait(1000)
    hamster.leds(0)
    wait(200)

# 첫 번째 모스 부호 (.--.)
def send_morse1():
    blink_short()
    blink_long()
    blink_long()
    blink_short()

# 두 번째 모스 부호 (-..-)
def send_morse2():
    blink_long()
    blink_short()
    blink_short()
    blink_long()

send_morse1()
```

**두 번째 햄스터 로봇** — 밝기 센서로 LED의 밝기를 감지하고 LED가 켜진 시간을 측정해 모스 부호를 알아낸다. 첫 번째 모스 부호에는 잠시 뒤로 물러났다가 왼쪽으로 회전하고, 두 번째 모스 부호에는 잠시 뒤로 물러났다가 오른쪽으로 회전한다.
```python
from roboid import *

hamster = HamsterS()

# 첫 번째 모스 부호에 대한 동작
def act1():
    hamster.wheels(-30)
    wait(1000)
    hamster.wheels(-30, 30)
    wait(1000)
    hamster.stop()

# 두 번째 모스 부호에 대한 동작
def act2():
    hamster.wheels(-30)
    wait(1000)
    hamster.wheels(30, -30)
    wait(1000)
    hamster.stop()

tick = 0
code = ''

while True:
    if hamster.light() < 10:  # 어두우면
        if tick > 0:
            if tick > 40:  # 밝은 시간이 길다.
                code += '-'
            else:  # 밝은 시간이 짧다.
                code += '.'

            print(code)  # 모스 부호 확인.
            if code == '.--.':
                code = ''
                act1()
            if code == '-..-':
                code = ''
                act2()

        tick = 0
    elif hamster.light() > 20:  # 밝으면
        tick += 1

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

두 대의 햄스터 로봇을 서로 마주 보게 하여 뽀뽀하듯 가까이 붙여 놓는다. 두 번째 햄스터 로봇의 코드를 먼저 실행하여 모스 부호를 받을 준비가 되면, 첫 번째 햄스터 로봇의 코드를 실행하여 모스 부호를 전달한다. 다양한 모스 부호를 만들어 친구에게 비밀스러운 명령을 전달해본다.

## 03 엉덩이 치면 앞으로 가기 (111–112p)

햄스터 로봇의 3축 가속도 센서 좌표계는 로봇의 앞쪽 방향이 X축, 왼쪽 방향이 Y축, 위쪽 방향이 Z축의 양수 방향이며, 각각 -32768 ~ 32767의 값을 가진다.

코드를 작성하기 전에 우선 가속도 센서의 값을 관찰해본다. 햄스터 로봇을 뒤집거나 옆으로 눕혔을 때 가속도 값이 어떻게 달라지는지, 손에 쥐고 이리저리 손목을 움직이면서 값을 확인해본다.
```python
from roboid import *

hamster = HamsterS()

while True:
    print(hamster.acceleration_x(), hamster.acceleration_y(), hamster.acceleration_z())
    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

햄스터 로봇의 엉덩이를 손가락으로 툭 치면 X축 방향으로 가속도가 작용한다. 이를 감지하여 1초 동안 앞으로 가게 한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.acceleration_x() > 2000:  # 엉덩이를 툭 쳤으면
        hamster.wheels(30)  # 앞으로 이동한다.
        wait(1000)
        hamster.stop()  # 1초 후에 정지한다.

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

어느 방향으로든 햄스터 로봇을 손가락으로 툭 치면 1초 동안 앞으로 가도록 코드를 수정해본다.

## 04 긴급구조 (113p)

햄스터 로봇에 내장된 가속도 센서를 사용하여 로봇이 넘어졌다는 것을 감지한다.

햄스터 로봇이 똑바로 서있으면 중력에 의해 아래쪽으로만 가속도가 생기므로 가속도의 Z축 성분만 음수로 크기가 큰 값을 가지고, X축·Y축 성분의 크기는 작은 값을 가진다. 로봇이 앞뒤로 혹은 왼쪽·오른쪽으로 넘어졌을 때는 Z축 성분의 크기가 작아지고 X축 또는 Y축 성분의 크기는 커진다는 것을 알 수 있다. 따라서 Z축 성분의 크기가 작거나 양수이면 로봇이 넘어졌다고 판단할 수 있다.

```python
from roboid import *

hamster = HamsterS()

tick = 0
while True:
    if hamster.acceleration_z() > -2048:  # z축 가속도 값이 작거나 양수이면
        # 일정 시간 간격으로 삐삐삐~ 소리 낸다.
        tick += 1
        if tick <= 10:  # 0.2초까지
            hamster.buzzer(1000)
        elif tick <= 20:  # 0.4초까지
            hamster.buzzer(0)
        else:
            tick = 0
    else:
        hamster.buzzer(0)
        tick = 0

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

## 05 시소놀이 (114–115p)

얇은 판을 연필이나 볼펜 위에 올려 시소처럼 움직이는 경사로를 만든다. 미로판의 검은색 바닥 판 한 장을 얇은 판으로 사용해도 된다. 햄스터 로봇이 경사로를 올라갈 수 있도록 한 쪽 끝에 올려 놓는다.

- 햄스터 로봇의 X축 가속도 값을 관찰해 보면, 중력이 아래쪽으로 작용하기 때문에 수평으로 놓여진 경우에는 아주 작은 값을 가진다.
- 경사로를 내려갈 때는 X축 가속도 값이 양수 값으로 절대치가 커지고, 경사로를 올라갈 때는 음수 값으로 절대치가 커진다.

왼쪽 그림과 같이 관찰 결과를 바탕으로 시소 놀이를 만든다. 햄스터 로봇이 경사로를 올라가서 중앙을 넘어가면 로봇의 무게 때문에 얇은 판의 앞쪽이 시소처럼 아래로 기울어진다. 이 때문에 X축 가속도 값이 바뀌게 되고 이를 감지하여 로봇이 뒤로 이동하게 한다. 뒤로 이동하면서 중앙을 넘어가면 얇은 판의 뒤쪽이 아래로 기울어진다. 이를 감지하여 다시 앞으로 이동하는 것을 반복하게 한다.

```python
from roboid import *

hamster = HamsterS()
while True:
    accX = hamster.acceleration_x()  # X축 가속도 값
    if accX > 1500:  # 앞쪽이 아래로 기울어졌다.
        hamster.wheels(-30)  # 뒤로 이동한다.
    elif accX < -1500:  # 뒤쪽이 아래로 기울어졌다.
        hamster.wheels(30)  # 앞으로 이동한다.

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

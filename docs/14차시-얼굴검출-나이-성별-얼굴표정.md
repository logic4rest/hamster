# 14차시 — 얼굴 검출 / 나이, 성별, 얼굴 표정

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 217–231쪽

`roboidai`의 `FaceDetector`, `AgeGenderDetector`, `FacialExpression` 클래스로 카메라 영상 속 얼굴을 검출하고, 나이·성별·표정을 추정한다.

## 01 영상처리 관련 클래스, 메소드 안내 (218–227p)

### 얼굴 검출 — FaceDetector 클래스의 메소드

| 메소드 | 설명 |
|---|---|
| `FaceDetector(threshold=0.5)` | 얼굴 검출 객체를 생성한다. `threshold`: 신뢰도가 이 값 이상인 경우에만 얼굴로 인정. 반환 값: 얼굴 검출 객체 |
| `detect(image, padding=0)` | 얼굴을 검출한다. `image`: 입력 영상(numpy.ndarray). `padding`: 검출한 얼굴 영역을 왼쪽, 오른쪽, 위, 아래로 padding만큼 영역을 넓힘. 반환 값: `True`(성공), `False`(실패) |
| `draw_result(image, color=(0,255,0), thickness=2, clone=False)` | 검출된 얼굴 영역을 표시한다. `color`: 사각형 테두리 색깔(BGR). `thickness`: 테두리 두께(픽셀). `clone`: `True`면 입력 영상을 복제한 영상에 표시(원본 유지), `False`면 복제 안 함. 반환 값: 얼굴 영역이 표시된 영상 |
| `get_box()` | 검출된 얼굴 영역 사각형의 좌표를 반환한다. 반환 값: `[x1, y1, x2, y2]` 또는 `None`(검출된 얼굴이 없는 경우) |
| `get_conf()` | 검출된 얼굴 영역의 신뢰도를 반환한다. 반환 값: 0.0~1.0 |
| `get_width()` | 검출된 얼굴 영역 사각형의 폭을 반환한다. |
| `get_height()` | 검출된 얼굴 영역 사각형의 높이를 반환한다. |
| `get_area()` | 검출된 얼굴 영역 사각형의 넓이를 반환한다. |
| `get_xy(id='all')` | 검출된 얼굴에서 각 요소의 좌표를 반환한다. `id`: `'all'`, `'left eye'`, `'right eye'`, `'nose'`, `'mouth'`, `'left ear'`, `'right ear'`. `id`가 `'all'`이면 모든 요소의 좌표 리스트(numpy.ndarray), 그 외에는 해당 얼굴 요소의 좌표 |
| `crop(image, clone=False)` | `image`에서 검출된 얼굴 영역을 잘라내어 반환한다. `clone`: `True`면 입력 영상을 복제한 후 잘라냄(원본 유지), `False`면 복제 안 함. 반환 값: 잘라 낸 얼굴 영상 또는 `None`(검출된 얼굴이 없는 경우) |

### 나이·성별·표정 검출

| 메소드 | 설명 |
|---|---|
| `AgeGenderDetector()` | 객체를 생성한다. 반환 값: 나이·성별 검출 객체 |
| `load_age_model(folder=None)` | 나이에 대한 모델 파일을 읽는다. `folder`: `age.caffemodel` 파일과 `age.prototxt` 파일이 있는 폴더 경로, `None`이면 `c:/roboid/model` 폴더로 함. 반환 값: `True`(성공), `False`(실패) |
| `load_gender_model(folder=None)` | 성별에 대한 모델 파일을 읽는다. `folder`: `gender.caffemodel` 파일과 `gender.prototxt` 파일이 있는 폴더 경로. 반환 값: `True`(성공), `False`(실패) |
| `download_age_model(folder=None, overwrite=False)` | 나이에 대한 모델 파일을 인터넷에서 내려 받는다. |
| `download_gender_model(folder=None, overwrite=False)` | 성별에 대한 모델 파일을 인터넷에서 내려 받는다. |
| `detect(image, gpu=False)` | 나이와 성별을 검출한다. `image`: 입력 영상. `gpu`: GPU 사용 여부. 반환 값: `True`(성공), `False`(실패) |
| `draw_result(image, color=(0,255,0), thickness=2, clone=False)` | 얼굴 영역과 결과 레이블을 표시한다. 반환 값: 결과가 표시된 영상 |
| `get_age_index()` | 검출된 나이의 인덱스를 반환한다. `['0-2', '4-6', '8-12', '15-20', '25-32', '38-43', '48-53', '60-100']`에 대한 인덱스, 검출 실패 시 -1 |
| `get_age_label()` | 검출된 나이의 레이블을 반환한다. `'0-2'`, `'4-6'`, `'8-12'`, `'15-20'`, `'25-32'`, `'38-43'`, `'48-53'`, `'60-100'` 중 하나, 검출 실패 시 빈 문자열 |
| `get_age_conf()` | 검출된 나이의 신뢰도를 반환한다(0.0~1.0). |
| `get_gender_index()` | 검출된 성별의 인덱스를 반환한다. `['male', 'female']`에 대한 인덱스, 검출 실패 시 -1 |
| `get_gender_label()` | 검출된 성별의 레이블을 반환한다. `'male'`, `'female'` 중 하나, 검출 실패 시 빈 문자열 |

## 01 얼굴 검출 실습 (228–229p)

얼굴 검출 실습을 위한 코드를 작성한다.

```python
import roboidai as ai

cam = ai.Camera('usb0')  # USB 카메라를 사용한다(웹캠).
dt = ai.FaceDetector()  # 얼굴 검출 클래스 객체 생성

while True:
    image = cam.read()
    if dt.detect(image):  # 사물이 검출되면
        image = dt.draw_result(image)  # 검출된 사물을 image에 표시한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

`padding`을 사용해보고, 신뢰도를 출력해본다. `padding`을 사용하면 검출한 얼굴 영역을 왼쪽, 오른쪽, 위, 아래로 padding만큼 영역을 넓힌다.

```python
import roboidai as ai

cam = ai.Camera('usb0', flip='h')  # USB 카메라를 사용한다(웹캠), 수평 반전
dt = ai.FaceDetector()  # 얼굴 검출 클래스 객체 생성

while True:
    image = cam.read()
    if dt.detect(image, padding=20):  # 얼굴이 검출되면
        print(dt.get_box(), dt.get_conf())  # 검출된 얼굴 영역 사각형의 좌표와 신뢰도를 출력한다.
        image = dt.crop(image)  # image에서 검출된 얼굴 영역을 잘라내어 반환한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

## 02 나이, 성별 검출 (230p)

나이, 성별 검출 실습을 위한 코드를 작성한다.

```python
import roboidai as ai

cam = ai.Camera('usb0', flip='h')  # USB 카메라를 사용한다(웹캠), 수평 반전
dt = ai.AgeGenderDetector()  # 나이, 성별 검출 클래스 객체 생성

dt.download_age_model()  # 모델 파일을 인터넷에서 내려 받는다.
dt.download_gender_model()

dt.load_age_model()  # 모델 파일을 읽는다.
dt.load_gender_model()

while True:
    image = cam.read()
    if dt.detect(image):  # 인식 성공 시
        image = dt.draw_result(image)  # 검출된 사물을 image에 표시한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

## 03 얼굴 표정 검출 (231p)

얼굴 표정 검출 실습을 위한 코드를 작성한다.

```python
import roboidai as ai

cam = ai.Camera('usb0', flip='h')  # USB 카메라를 사용한다(웹캠), 수평 반전
dt = ai.FacialExpression('ko')  # 얼굴 표정 검출 클래스 객체 생성

dt.load_model()  # 모델 파일을 읽는다.

while True:
    image = cam.read()
    if dt.detect(image):  # 인식 성공 시
        image = dt.draw_result(image, show_conf=True)  # 결과와 신뢰도를 image에 표시한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

# 4차시 — 순서대로 반복하여 명령하기

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 62–75쪽

`wait()`로 시간을 제어하고, 순차 명령·반복문(`for`, `while`)을 조합해 다양한 동작(사각형 이동, 램덤 룰렛, 노래 연주, 사이렌, LED 점멸, 랜덤 워크)을 만든다.

---

## 01 일정 시간 동안 움직이기 (63p)

`wait()` 함수를 사용하면 코드의 다음 줄로 넘어가지 않고 일정 시간(msec) 동안 기다릴 수 있다.

```python
from roboid import *

hamster = HamsterS()

hamster.wheels(30)  # 앞으로 이동한다.
wait(1000)  # 1초 기다린다.
hamster.stop()
```

1초 동안 후진하거나 회전하기 등 다양한 동작을 만들어본다.

---

## 02 햄스터 룰렛 (64p)

햄스터 로봇이 무작위 시간 동안 제자리에서 돌게 하여 룰렛 게임을 만든다. 파이썬의 `random` 모듈에 있는 `randint(low, high)` 함수는 low부터 high까지의 무작위 정수를 반환한다. `random` 모듈을 사용하기 위해서는 `import random`이 필요하다.

- 룰렛 게임판 내려 받기(PDF): http://hamster.school/repository/tutorial/class/roulette_pdf_ko.zip

1초부터 10초까지의 무작위 시간 동안 제자리에서 돌게 한다.
```python
import random
from roboid import *

hamster = HamsterS()

hamster.wheels(-30, 30)  # 제자리에서 왼쪽으로 돈다.
wait(random.randint(1000, 10000))  # 1초부터 10초까지의 무작위 시간 동안 기다린다.
hamster.stop()
```

햄스터 로봇이 제자리에서 도는 속도를 10부터 100까지의 무작위 속도로 해본다.

## 03 순서대로 명령하기 (순차) (65p)

1초 동안 앞으로 이동한 후 1초 동안 뒤로 이동한다.

```python
from roboid import *

hamster = HamsterS()

hamster.wheels(30)  # 1초 동안 앞으로 이동한다.
wait(1000)

hamster.wheels(-30)
wait(1000)

hamster.stop()
```

- 1초 동안 앞으로 이동한 후 1초 동안 제자리에서 왼쪽 또는 오른쪽으로 돌게 해본다.
- A4 용지 위에 사각형과 원을 그리고, 햄스터 로봇이 장애물(사각형)을 피해 오른쪽 원 안으로 들어가도록 왼쪽 바퀴와 오른쪽 바퀴의 속도 및 시간을 설정해 여러 명령을 순서대로 수행해본다.
- 목표 지점으로 갔다가 출발 지점으로 다시 되돌아 오도록 해본다.

## 04 노래 연주하기 (66p)

hamster.note(hamster.NOTE_A_4, 0.5)  # 4옥타브 라 음을 0.5 박자 소리낸다.
hamster.note(hamster.NOTE_A_4, 0.5)  # 4옥타브 라 음을 0.5 박자 소리낸다.

## 05 사각형 모양으로 이동하기 (67–68p)

사각형 모양으로 이동하려면 90도로 회전해야 하는데, 실험을 통해 몇 초 동안 회전하면 90도가 되는지 알아본다. 아래 코드의 `950`이라는 숫자는 실험 환경에 따라 달라질 수 있다.

```python
from roboid import *

hamster = HamsterS()

hamster.wheels(30)
wait(1000)

hamster.wheels(30, -30)
wait(950)

hamster.wheels(30)
wait(1000)

hamster.wheels(30, -30)
wait(950)

hamster.wheels(30)
wait(1000)

hamster.wheels(30, -30)
wait(950)

hamster.wheels(30)
wait(1000)

hamster.wheels(30, -30)
wait(950)

hamster.stop()
wait(100)
```

코드를 작성한 후 실행해 보면 햄스터 로봇이 정확하게 사각형 모양으로 이동할 수도, 약간 찌그러진 모양으로 이동할 수도 있다. 바닥의 재질에 따라서는 완전히 이상한 모양으로 이동할 수도 있다. 사람이 눈을 감고 사각형 모양으로 걸어가는 것과 같은데, 센서를 사용하지 않기 때문이다. 로봇에게 센서는 사람의 눈과 같다. 따라서 센서를 사용하지 않고 이동하는 것에는 한계가 있을 수밖에 없으며, 햄스터 로봇이 센서를 사용해 이동하는 방법은 앞으로 하나씩 배우게 된다.

직사각형, 삼각형, 다이아몬드 등 다양한 모양으로 이동해본다.

## 06 횟수 반복하기 (69p)

앞서 작성한 코드처럼 같은 내용을 반복하여 작성하는 것은 비효율적이다. 반복문을 사용하여 간략하게 작성한다.

```python
from roboid import *

hamster = HamsterS()

for i in range(4):
    hamster.wheels(30)
    wait(1000)

    hamster.wheels(30, -30)
    wait(950)

hamster.stop()
wait(100)
```

반복문을 사용해 직사각형, 삼각형, 다이아몬드 등 다양한 모양으로 이동해본다.

## 07 서서히 출발하기 (70p)

로봇이 이동할 때 서서히 속도를 높이거나 내리는 것은 중요하다. 속도를 서서히 높이려면 속도 값을 계속 다르게 주어야 한다.

속도를 0에서 50까지 1씩 증가시키며 출발한다.
```python
from roboid import *

hamster = HamsterS()

for speed in range(51):  # 속도를 1씩 증가시킨다.
    hamster.wheels(speed)
    wait(20)  # 20msec마다 속도를 증가시킨다
```

속도를 50에서 시작해 0까지 1씩 감소시켜 정지한다. 속도가 0이 되면 더 이상 감소시키지 않아야 한다.
```python
from roboid import *

hamster = HamsterS()

for speed in reversed(range(51)):  # 속도를 1씩 감소시킨다.
    hamster.wheels(speed)
    wait(20)  # 20msec마다 속도를 감소시킨다
```

## 08 계속 반복하기 (71p)

햄스터 로봇이 1초 동안 앞으로 이동한 후 1초 동안 뒤로 이동하는 것을 계속 반복하게 한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(30)  # 1초 동안 앞으로 이동한다.
    wait(1000)

    hamster.wheels(-30)  # 1초 동안 뒤로 이동한다.
    wait(1000)
```

`while` 문 내부의 명령을 계속 반복하기 때문에 코드가 계속 수행된다. 이런 경우에는 파이썬 쉘의 Shell → Restart Shell 메뉴를 선택하거나 윈도우를 닫아서 실행을 종료할 수도 있지만, 키보드의 컨트롤(Ctrl) 키와 알파벳 C 키를 동시에 눌러 코드 수행을 중지할 수도 있다.

## 09 LED 계속 깜빡이기 (72p)

자동차의 비상등처럼 햄스터 로봇의 양쪽 LED를 계속 깜빡이게 한다. 양쪽 LED를 0.2초 동안 노란색으로 켜고 0.2초 동안 끄는 것을 계속 반복한다.

```python
from roboid import *

hamster = Hamster()

while True:
    hamster.leds(hamster.LED_YELLOW)  # 양쪽 LED를 노란색으로 켠다.
    wait(200)  # 0.2초 기다린다.

    hamster.leds(0)  # 양쪽 LED를 끈다.
    wait(200)  # 0.2초 기다린다.
```

햄스터 로봇의 버저 소리를 일정 시간 간격으로 삐삐삐~ 계속 반복하여 내보게 해본다.

## 10 예술가 로봇 (73p)

무작위로 움직이는 것을 **랜덤 워크**(Random Walk)라 한다.

```python
from roboid import *
import random

hamster = HamsterS()
while True:
    # 양쪽 바퀴의 속도를 -50부터 50까지 무작위로 설정한다.
    hamster.wheels(random.randint(-50, 50), random.randint(-50, 50))

    # 0.5초부터 1초까지의 무작위 시간 동안 기다린다.
    wait(random.randint(500, 1000))
```

햄스터 로봇에 다양한 색상의 펜을 테이프 등으로 부착하고 A4 용지 위에 올려놓은 후 코드를 실행하면 멋진 추상화 그림을 그리는 예술가 로봇이 된다. 양쪽 바퀴 속도의 범위 또는 기다리는 시간의 범위를 변경하면서 로봇이 그림을 그리는 형태가 어떻게 달라지는지 관찰해본다.

## 11 사이렌 소리 내기 (74p)

버저 소리의 음 높이를 500부터 700까지 10씩 증가시키는 것을 계속 반복한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    for hz in range(500, 701, 10):  # 500부터 700까지 반복한다.
        hamster.buzzer(hz)
        wait(20)
```

사이렌 소리와 함께 양쪽 LED도 빨간색으로 계속 깜빡이게 해본다.

## 12 LED 깜빡이다 멈추기 (75p)

자동차가 좌회전할 때처럼 햄스터 로봇이 왼쪽으로 회전하는 동안 LED를 깜빡이게 한다.

```python
from roboid import *

hamster = Hamster()

for i in range(5):                    # 5번 반복하면 2초가 된다.
    hamster.wheels(10, 40)             # 왼쪽으로 둥글게 회전한다.
    hamster.left_led(hamster.LED_YELLOW)  # 왼쪽 LED를 노란색으로 켠다.
    wait(200)                          # 0.2초 기다린다.

    hamster.left_led(0)                # 왼쪽 LED를 끈다.
    wait(200)                          # 0.2초 기다린다.

hamster.stop()                         # 정지한다.
```

햄스터 로봇이 2초 뒤로 이동하는 동안 버저 소리를 일정 시간 간격으로 삐삐삐~ 계속 반복하여 내보게 해본다.

# 5차시 — 근접센서 사용하기 / 말판 이동하기2

근접 센서로 장애물과의 거리를 측정해 정지·회전·밀당·손 연주·애완로봇 등 다양한 반응형 동작을 만들고, 근접 센서와 말판 이동 메소드를 조합해 벽을 피해 미로를 통과하는 "얼음 나라"를 만든다.

## 01 장애물 감지하기 (77–81p)

햄스터 로봇의 전방에 있는 근접 센서는 적외선을 방출하는 IR-LED와 적외선을 감지하는 광 트랜지스터로 이루어져 있다.

- 광 트랜지스터는 IR-LED가 방출하는 적외선이 전방의 물체에 반사되어 들어오는 광량을 측정한다.
- 장애물이 가까이 있으면 반사된 광량이 많아서 측정값이 증가하고, 장애물이 멀면 반사된 광량이 적어서 측정값이 감소한다.
- 장애물이 없으면 반사된 빛이 없어 0의 값을 가진다.
- 근접 센서는 IR-LED가 로봇의 앞면 좌우에 하나씩 설치되어 있으며, 중앙 아래에 광 트랜지스터가 있어서 좌우의 IR-LED에 대한 광량을 번갈아 측정한다.
- 전방의 1cm 이상, 30cm 이하 거리에 있는 물체나 장애물을 감지할 수 있으며, 0부터 255까지의 값을 가진다.

코드를 작성하기 전에 장애물과의 거리에 따라 근접 센서의 값이 어떻게 달라지는지 관찰해본다.
```python
from roboid import *

hamster = HamsterS()

while True:
    print(hamster.left_proximity(), hamster.right_proximity())  # Python 3
    # print hamster.left_proximity() hamster.right_proximity()  # Python 2.7.x
    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

- `while` 문 안에서 `wait(20)`과 같이 일정 시간 동안 기다리지 않으면 `while` 문이 너무 과도하게 빨리 수행되어 컴퓨터가 햄스터 로봇과 통신하는 일에 영향을 줄 수 있다.
- 컴퓨터와 햄스터 로봇이 약 20msec 주기로 통신하기 때문에 센서 값도 약 20msec마다 한 번씩 전달된다. 이 주기에 맞추어 20msec 동안 기다리도록 한다. (보통 10~20msec 정도로 하면 됨)
- 햄스터 로봇의 앞을 손으로 막고 손을 앞뒤로 움직여 거리를 다르게 하면서 왼쪽·오른쪽 근접 센서 값이 어떻게 달라지는지 관찰해본다. 손을 너무 가까이 가져가면 센서 값이 측정되지 않을 수도 있다.
- 하얀색 종이였을 때와 다양한 색상의 물체였을 때 어떤 변화가 생기는지도 관찰해본다. 같은 거리에서 장애물의 색이 밝을수록 근접 센서의 값이 더 커지는데, 밝은 색일수록 반사되는 광량이 많아지기 때문이다.
- 센서 값을 관찰하고 분석하는 것은 매우 중요하므로 앞으로 새로운 센서를 사용할 때마다 반드시 이 방법으로 관찰하도록 한다.

**장애물 앞에서 정지하기** — `40`이라는 숫자는 장애물과의 거리에 따라 센서 값이 어떻게 되는지 관찰하여 정해준다.
```python
from roboid import *

hamster = HamsterS()

while hamster.left_proximity() < 40 and hamster.right_proximity() < 40:
    hamster.wheels(30)  # 앞으로 이동한다.
    wait(20)  # 너무 빨리 반복하지 않도록 한다.

hamster.stop()  # 정지한다.
```

**손을 치우면 다시 이동하기**
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() < 40 and hamster.right_proximity() < 40:
        hamster.wheels(30)  # 앞으로 이동한다.
    else:
        hamster.stop()  # 정지한다.

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

햄스터 로봇이 제자리에서 왼쪽으로 돌다가 앞에 장애물이 있으면 정지하게 해본다.

## 02 밀당 로봇 (82p)

햄스터 로봇이 앞으로 이동하다가 앞쪽 장애물과 가까우면 뒤로 물러나고, 장애물과 멀어지면 다시 앞으로 이동하여 장애물과 일정 거리를 두고 앞뒤로 움직인다.

```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() < 40 and hamster.right_proximity() < 40:
        hamster.wheels(30)  # 앞으로 이동한다.
    else:
        hamster.wheels(-30)  # 뒤로 이동한다.

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

장애물과 가까우면 근접 센서 값이 40보다 커져서 뒤로 물러나고, 뒤로 물러나 장애물과 멀어지면 근접 센서 값이 40보다 작아져서 다시 앞으로 이동하는 것을 반복한다. 숫자 40을 변경하여 장애물과의 거리를 조정해본다.

## 03 햄스터 탈출을 막아라 (83p)

앞으로 이동하는 햄스터 로봇의 앞을 손으로 막으면 회전하여 방향을 바꾸고 다시 앞으로 이동하도록 한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() < 40 and hamster.right_proximity() < 40:
        hamster.wheels(30)  # 앞으로 이동한다.
    else:
        hamster.wheels(-30, 30)  # 1초 동안 왼쪽으로 회전한다.
        wait(1000)

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

햄스터 로봇과 손 간의 거리에 따라 회전하는 시간이 달라지도록 해본다.

## 04 손으로 연주하기 (84p)

햄스터 로봇과 손 간의 거리에 따라 음정을 변경한다.

```python
from roboid import *

hamster = HamsterS()

pitch = 0
while True:
    proximity = hamster.left_proximity()
    if proximity < 10:  # 거리가 너무 멀면 0으로 설정한다.
        proximity = 0

    # 이전 음정과 현재 근접 센서 값을 조합하여 음정이 부드럽게 변하도록 한다.
    pitch = (pitch * 9 + proximity) / 10.0
    hamster.note(pitch)

    wait(20)  # 너무 빨리 반복하지 않도록 설정한다.
```

## 05 애완로봇 (85–86p)

햄스터 로봇의 앞에 손을 멀리 가져가면 따라오고, 가깝게 가져가면 뒤로 도망가는 애완 로봇을 만든다.

```python
from roboid import *

hamster = HamsterS()

while True:
    proximity = hamster.left_proximity()  # 왼쪽 근접 센서 값
    if proximity > 15:
        left_speed = (40 - proximity) * 4  # 거리가 멀면 앞으로, 가까우면 뒤로 이동한다.
    else:
        left_speed = 0  # 거리가 너무 멀면 정지한다.

    proximity = hamster.right_proximity()  # 오른쪽 근접 센서 값
    if proximity > 15:
        right_speed = (40 - proximity) * 4  # 거리가 멀면 앞으로, 가까우면 뒤로 이동한다.
    else:
        right_speed = 0  # 거리가 너무 멀면 정지한다.

    hamster.wheels(left_speed, right_speed)

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

- 햄스터 로봇과 손 간의 거리가 가까우면 근접 센서 값이 40보다 커져서 바퀴 속도가 음수가 되고, 거리가 멀면 근접 센서 값이 40보다 작아져서 바퀴 속도가 양수가 된다.
- 왼쪽 바퀴 속도는 왼쪽 근접 센서 값에 의해, 오른쪽 바퀴 속도는 오른쪽 근접 센서 값에 의해 결정되기 때문에 손을 가져가는 방향에 따라 로봇의 움직임이 달라진다.
- 손바닥을 약간 둥근 모양으로 하면 햄스터 로봇이 더 잘 움직인다.

공통적인 부분을 함수로 만들면 좀 더 간략하게 작성할 수 있다.
```python
from roboid import *

hamster = HamsterS()

def calc_speed(proximity):
    if proximity > 15:
        return (40 - proximity) * 4  # 거리가 멀면 앞으로, 가까우면 뒤로 이동한다.
    else:
        return 0  # 거리가 너무 멀면 정지한다.

while True:
    left_speed = calc_speed(hamster.left_proximity())
    right_speed = calc_speed(hamster.right_proximity())

    hamster.wheels(left_speed, right_speed)

    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

## 06 얼음 나라 (87–89p)

햄스터 로봇이 펭귄 친구를 만나러 얼음 나라에 간다. 얼음 나라는 길이 얼음으로 되어 있어 너무 미끄러워서 **길 위에서는 방향을 바꿀 수 없다.** 벽이 나타날 때까지 계속 앞으로 미끄러져 이동하다가 벽을 잡고 방향을 바꾸어야 한다. 도착 지점으로 이동한 후에는 펭귄 방향을 바라보아야 한다.

- 햄스터 로봇이 아직 그림으로 그려진 벽은 알 수 없으므로 말판 위에 벽을 세워 놓아야 한다. 그림의 손과 방향을 맞추어 손을 올려놓도록 한다.
- 1차시(38p)에서 내려받은 '말판 내려 받기(PDF)'의 도안(`move_on_board.pdf`, 13~16p)을 활용한다.
- 근접 센서의 값은 상황에 따라 적절한 값으로 변경해도 된다.

**펭귄 친구 1**
```python
from roboid import *

hamster = HamsterS()

def can_move_forward():
    return hamster.left_proximity() < 40 and hamster.right_proximity() < 40

while (can_move_forward()):
    hamster.board_forward()
hamster.board_left()
```

**펭귄 친구 2**
```python
from roboid import *

hamster = HamsterS()

def can_move_forward():
    return hamster.left_proximity() < 40 and hamster.right_proximity() < 40

for i in range(2):
    while (can_move_forward()):
        hamster.board_forward()
    hamster.board_left()
```

**펭귄 친구 3**
```python
from roboid import *

hamster = HamsterS()

for i in range(4):
```

```python
from roboid import *
```

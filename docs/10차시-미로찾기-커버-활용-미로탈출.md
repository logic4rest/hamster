# 10차시 — 미로찾기 커버 활용 – 미로탈출

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 162–179쪽

미로찾기 커버(반사판)를 활용해 한쪽 벽 따라가기 → 양쪽 벽 사이 중앙 주행 → 비례 제어로 부드럽게 다듬기 → 막힌 길에서 제자리 돌기 → 좌수법으로 미로 전체를 탈출하는 순서로 단계를 높여간다.

---

## 01 미로 탈출 (163–179p)

### 한쪽 센서로 벽 따라가기

한 쪽 센서를 사용하여 벽을 따라갈 수 있도록 한다. 반사판을 끼운다.

```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() > 35:
        hamster.wheels(50, 0)
    else:
        hamster.wheels(0, 50)
    wait(10)
```

### 양쪽 센서로 복도 중앙 주행

양쪽 센서를 사용하여 벽을 따라갈 수 있도록 한다. 반사판을 끼운다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(50, 50)
    if hamster.left_proximity() > 35:
        hamster.wheels(50, -50)
    elif hamster.right_proximity() > 35:
        hamster.wheels(-50, 50)
    wait(10)
```

왼쪽 센서 값과 오른쪽 센서 값의 차이를 이용해서 주행해본다. 왼쪽 센서 값 > 오른쪽 센서 값이면 `hamster.left_proximity() - hamster.right_proximity() > 0`, 반대면 `< 0`이다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(50, 50)
    diff = hamster.left_proximity() - hamster.right_proximity()
    if diff > 0:
        hamster.wheels(50, -50)
    elif diff < 0:
        hamster.wheels(-50, 50)
    wait(10)
```

### 차이에 비례해 속도 조절하기

위 코드를 실행해보고 문제점이 무엇인지 알아본다. 왼쪽 센서와 오른쪽 센서의 차이에 따라 속도를 조절할 수 있도록 한다. 차이가 큰 경우 더 많이 움직이고, 차이가 적은 경우 더 조금 움직여야 한다는 것을 코드로 표현한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    diff = hamster.left_proximity() - hamster.right_proximity()

    hamster.wheels(50 + diff * 1.3, 50 - diff * 1.3)

    wait(10)
```

### 왼쪽 벽만 따라가기(개선판)

왼쪽 반사판으로 교체한다. 왼쪽 벽을 따라 주행하는 코드 또한 일정 조건이 아니라 차이를 이용하여 작성한다.

기존 코드:
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() > 35:
        hamster.wheels(50, 0)
    else:
        hamster.wheels(0, 50)
    wait(10)
```

개선한 코드:
```python
from roboid import *

hamster = HamsterS()

while True:
    diff = hamster.left_proximity() - 35

    hamster.wheels(50 + diff * 0.8, 50 - diff * 0.8)

    wait(10)
```

### 모퉁이에서 제자리 돌기

미로에서 모퉁이에 부딪히는지 확인해본다. 막힌 길에서 제자리를 돌아보도록 한다. 센서 값을 활용해 언제까지 돌아야 하는지 생각해보고 코드를 작성한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    left = hamster.left_proximity()
    right = hamster.right_proximity()

    if right > 47:
        while right > 5:
            hamster.wheels(50, -50)
            right = hamster.right_proximity()
            wait(10)
    else:
        diff = left - 35
        hamster.wheels(50 + diff * 0.8, 50 - diff * 0.8)

    wait(10)
```

### 좌수법(좌선법)으로 미로 전체 탈출하기

**좌수법(좌선법)**: 왼쪽 → 앞쪽 → 오른쪽 순으로 우선순위를 둔다. 왼쪽 벽을 따라 주행하고, 앞쪽에 벽이 있으면 벽이 없을 때까지 오른쪽으로 회전한다. 왼쪽 반사판을 끼운다.

```python
from roboid import *

hamster = HamsterS()

while True:
    left = hamster.left_proximity()
    right = hamster.right_proximity()

    if right > 47:
        while right > 5:
            hamster.wheels(50, -50)
            right = hamster.right_proximity()
            wait(10)
    else:
        diff = left - 35
        hamster.wheels(50 + diff * 0.8, 50 - diff * 0.8)

    wait(10)
```

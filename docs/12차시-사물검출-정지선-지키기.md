## 01 영상처리 관련 클래스, 메소드 안내 (190–195p)

### 사물 검출 — ObjectDetector 클래스의 메소드

| 메소드 | 설명 |
|---|---|
| `ObjectDetector(multi=False, lang='en')` | 사물 검출 객체를 생성한다. `multi`: `True`면 모든 사물 검출, `False`면 영역이 가장 큰 사물 하나만 검출. `lang`: 레이블 언어, `'en'` 또는 `'ko'`. 반환 값: 사물 검출 객체 |
| `load_model(folder=None)` | 모델 파일을 읽는다. `folder`: `object.weights` 파일과 `object.cfg` 파일이 있는 폴더의 경로, `None`이면 `c:/roboid/model` 폴더로 함. 반환 값: `True`(성공), `False`(실패) |
| `download_model(folder=None, overwrite=False)` | 모델 파일을 인터넷에서 내려 받는다. `folder`: 내려 받을 폴더 경로(없으면 생성, `None`이면 `c:/roboid/model`). `overwrite`: 파일이 이미 있는 경우 `True`면 덮어씀, `False`면 내려받지 않음 |
| `detect(image, conf_threshold=0.5, nms_threshold=0.4, gpu=False)` | 사물을 검출한다. `image`: 입력 영상(numpy.ndarray). `conf_threshold`: 신뢰도가 이 값 이상인 경우에만 사물로 인정. `nms_threshold`: Non-Maximum Suppression, 중복된 박스 제거를 위한 문턱값. `gpu`: GPU 사용 여부. 반환 값: `True`(성공), `False`(실패) |
| `draw_result(image, colors=None, show_conf=False)` | 검출된 사물을 표시한다. `image`: 입력 영상. `colors`: 각 사물의 사각형 테두리 및 레이블 색깔들(`None`이면 자동). `show_conf`: 신뢰도 표시 여부. 반환 값: 검출된 사물 영역이 표시된 영상(numpy.ndarray) |
| `get_box()` | 검출된 사물 영역 좌표를 반환한다. `multi=False`로 생성한 경우 좌표 리스트 `[x1, y1, x2, y2]` 또는 `None`(검출된 사물이 없는 경우). `multi=True`로 생성한 경우 좌표 리스트의 리스트 `[[x1,y1,x2,y2], ..., [x1,y1,x2,y2]]` |
| `get_label()` | 검출된 사물의 레이블을 반환한다. `multi=False`면 레이블 문자열, `multi=True`면 레이블 문자열의 리스트 |
| `get_conf()` | 검출된 사물의 신뢰도를 반환한다. `multi=False`면 신뢰도 값(0.0~1.0), `multi=True`면 신뢰도 값의 리스트(예: `[0.9, 0.6, ..., 0.8]`) |

## 02 사물 검출 실습 (196p)

```python
import roboidai as ai

cam = ai.Camera('usb0')  # USB 카메라를 사용한다(웹캠).
dt = ai.ObjectDetector(multi=True, lang='ko')  # 모든 사물 검출하여 한국어로 사물 검출 객체 반환

dt.download_model()  # 모델 파일을 인터넷에서 내려 받는다.
dt.load_model()  # 모델 파일을 읽는다.

while True:
    image = cam.read()
    if dt.detect(image):  # 사물이 검출되면
        image = dt.draw_result(image)  # 검출된 사물을 image라고 저장한다.
        print(dt.get_label())  # 해당 사물의 라벨을 출력한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
```

## 03 정지 신호 지키기 (197–201p)

**준비물**: 검은색 원형 트랙(햄스터가 도는 링 모양 트랙)과 STOP 표지판(정지 신호) 그림을 준비해 트랙 옆에 세워 둔다.

정지 신호 인식을 위한 코드를 작성한다. 관련 메소드는 위 "01 영상처리 관련 클래스, 메소드 안내"를 참고한다.

```python
from roboid import *
import roboidai as ai

hamster = HamsterS()

cam = ai.Camera('usb0')  # USB 카메라를 사용한다(웹캠).
dt = ai.ObjectDetector(multi=True, lang='ko')  # 모든 사물 검출하여 한국어로 사물 검출 객체 반환

dt.download_model()  # 모델 파일을 인터넷에서 내려 받는다.
dt.load_model()  # 모델 파일을 읽는다.

hamster.line_both()

while True:
    image = cam.read()
    if dt.detect(image):  # 사물이 검출되면
        image = dt.draw_result(image)  # 검출된 사물을 image에 표시한다.
        print(dt.get_label())  # 해당 사물의 라벨을 출력한다.

        if '정지 신호' in dt.get_label():
            break

    cam.show(image)
    if cam.check_key() == 'esc': break

hamster.stop()
wait(100)
```

물체 검출 중 '정지 신호'가 검출된다면 `break`를 통해 `while`문을 탈출하게 된다. `while`문 이후에 햄스터를 멈추는 명령을 통해 햄스터를 멈추고 프로그램이 종료된다.

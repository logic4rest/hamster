# 9차시 — 미로찾기 커버 활용 – 슬라럼

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 149–161쪽

미로찾기 커버(반사판)를 조립해 근접 센서 감지 범위를 확장하고, 컵 하나를 도는 것부터 시작해 여러 컵 사이를 지그재그로 통과하는 슬라럼 주행까지 단계적으로 만든다.

---

## 01 컵 따라 돌기 (150–155p)

**커버 조립** — 커버를 햄스터 위에 씌운다.
**반사판 조립** — 위에서 누르면 끼울 수 있고, 뒤에서 앞으로 밀면 뺄 수 있다.

**Beginner** — 왼쪽 근접 센서 값에 따라 양쪽 바퀴의 속도가 바뀌며 회전한다. 왼쪽 센서 값이 10보다 커지면 왼쪽 바퀴가 오른쪽 바퀴보다 빨리 돌아 컵에 부딪히지 않게 주행하고, 왼쪽 센서 값이 10보다 작아지면 오른쪽 바퀴가 왼쪽보다 빨리 돌아 컵 쪽으로 주행한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() > 10:  # 왼쪽 근접 센서의 값이 10보다 커지면
        hamster.wheels(30, 0)  # 왼쪽 바퀴의 속도를 30, 오른쪽 바퀴의 속도를 0으로 설정한다.
    else:  # 왼쪽 근접 센서의 값이 10보다 작으면
        hamster.wheels(0, 30)  # 왼쪽 바퀴의 속도를 0, 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

**Intermediate(개선된 컵 따라 돌기)** — 왼쪽 센서 값이 10보다 커지면 양쪽 바퀴가 같은 속도로 컵에 부딪히지 않게 주행하고, 10보다 작아지면 오른쪽 바퀴가 왼쪽보다 빨리 돌아 컵 쪽으로 주행한다.
```python
from roboid import *

hamster = HamsterS()

while True:  # 왼쪽 바퀴의 속도를 20, 오른쪽 바퀴의 속도를 40으로 설정한다.
    if hamster.left_proximity() > 10:  # 왼쪽 근접 센서의 값이 10보다 커지면
        hamster.wheels(30, 30)  # 왼쪽 바퀴의 속도를 30, 오른쪽 바퀴의 속도를 30으로 설정한다.
    else:  # 왼쪽 근접 센서의 값이 10보다 작아지면
        hamster.wheels(0, 30)  # 왼쪽 바퀴의 속도를 0, 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

**Advanced(원하는 거리만큼 떨어져서 돌기)** — 센서 위치를 컵의 중심에 맞춘다. 왼쪽 근접 센서의 값으로 양쪽 바퀴의 속도가 바뀌며 회전한다. 오른쪽 바퀴는 항상 30의 속도이고, 왼쪽 바퀴의 속도는 왼쪽 센서 값으로 설정하여 주행한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(hamster.left_proximity(), 30)
    # 왼쪽 바퀴의 속도는 왼쪽 센서의 값으로, 오른쪽 바퀴의 속도는 30으로 설정한다.
    wait(10)
```

센서 값이 16일 때 30÷16=1.875 배를 곱해 회전 반경(원하는 거리)을 조정한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(hamster.left_proximity()*1.875, 30)
    # 왼쪽 바퀴의 속도는 왼쪽 센서의 값(16)과 기존 바퀴 속도(30)을 센서(16)로 나눈 값을 곱하여 설정한다.
    # 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

## 02 슬라럼 (156–161p)

컵 두 개(또는 여러 개) 사이를 8자 모양으로 지그재그 주행한다. 컵 중간으로 지나가게 하려면 어떻게 해야 할까?

**4단계 상태 전환**
1. 오른쪽 컵을 발견할 때까지 왼쪽 컵 따라 돌기
2. 왼쪽 컵이 사라질 때까지 오른쪽 컵 따라 돌기
3. 왼쪽 컵을 발견할 때까지 오른쪽 컵 따라 돌기
4. 오른쪽 컵이 사라질 때까지 왼쪽 컵 따라 돌기

센서 값 노이즈에 대응하기 위해 "다른 컵 사라짐"은 센서 값 5 미만, "다른 컵 발견"은 15 초과를 기준값으로 하고, 그 사이(5~15)를 안전한 범위로 둔다. 짧은 순간의 노이즈에 흔들리지 않도록, 기준을 10회 이상 연속으로 만족할 때만 상태를 전환한다(`count > 10`).

**상태 다이어그램**

| 상태 | 동작 | 다음 상태로 전환 조건 |
|---|---|---|
| 상태 0 | 왼쪽 컵 따라 돌기 | 오른쪽 센서 > 15 → 상태 1 |
| 상태 1 | 오른쪽 컵 따라 돌기 | 왼쪽 센서 < 5 → 상태 2 |
| 상태 2 | 오른쪽 컵 따라 돌기 | 왼쪽 센서 > 15 → 상태 3 |
| 상태 3 | 왼쪽 컵 따라 돌기 | 오른쪽 센서 < 5 → 상태 0 |

```python
from roboid import *

hamster = HamsterS()

state = 0
count = 0  # 노이즈 값 세기
while True:
    left = hamster.left_proximity()
    right = hamster.right_proximity()
    if state == 0:
        hamster.wheels(left*2.5, 50)
        if right > 15:
            count += 1
        else:
            count = 0
        if count > 10:
            count = 0
            state = 1

    elif state == 1:
        hamster.wheels(50, right*2.5)
        if left < 5:
            count += 1
        else:
            count = 0
        if count > 10:
            count = 0
            state = 2

    elif state == 2:
        hamster.wheels(50, right*2.5)
        if left > 15:
            count += 1
        else:
            count = 0
        if count > 10:
            count = 0
            state = 3

    else:
        hamster.wheels(left*2.5, 50)
        if left < 5:
            count += 1
        else:
            count = 0
        if count > 10:
            count = 0
            state = 0
    wait(10)
```

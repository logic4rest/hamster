# 2차시 — 말판 이동하기1 / 이동하고 회전하기

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 37–54쪽

검은색 격자 말판 위에서 순차·반복 명령으로 햄스터를 이동시키는 법을 배우고, 이어서 바퀴 속도(`wheels`)를 직접 제어해 전진·후진·제자리 회전·피봇 턴·라운드 턴 등 다양한 움직임을 만든다.

---

## 01 동굴 탐험 (순차) (38–43p)

햄스터 로봇이 동굴 속을 탐험해 보물 상자 앞까지 이동한 뒤, 보물 상자를 열 수 있도록 그 방향을 바라보게 한다.

- 말판 내려 받기(PDF): http://hamster.school/repository/tutorial/class/move_on_board_pdf_ko.zip

| 메소드 | 설명 |
|---|---|
| `board_forward()` | 검은색 격자로 구성된 말판 위에서 한 칸 앞으로 이동한다 |
| `board_left()` | 검은색 격자로 구성된 말판 위에서 왼쪽 방향으로 제자리에서 90도 회전한다 |
| `board_right()` | 검은색 격자로 구성된 말판 위에서 오른쪽 방향으로 제자리에서 90도 회전한다 |

**동굴 탐험 1**
```python
from roboid import *

hamster = HamsterS()

hamster.board_forward()
hamster.board_right()
hamster.board_forward()
hamster.board_forward()
```

**동굴 탐험 2**
```python
from roboid import *

hamster = HamsterS()

hamster.board_forward()
hamster.board_forward()
hamster.board_right()
hamster.board_forward()
hamster.board_forward()
hamster.board_right()
hamster.board_forward()
hamster.board_forward()
```

**동굴 탐험 3**
```python
from roboid import *

hamster = HamsterS()

hamster.board_forward()
hamster.board_right()
hamster.board_forward()
hamster.board_left()
hamster.board_forward()
hamster.board_right()
hamster.board_forward()
hamster.board_left()
```

## 02 우물 찾기 (횟수 반복) (44–49p)

목이 마른 햄스터 로봇이 숲 속 우물까지 이동한 뒤, 물을 마실 수 있도록 우물 방향을 바라보게 한다. `for i in range(n):` 반복문으로 같은 명령을 여러 번 반복한다.

**우물 찾기 1**
```python
from roboid import *

hamster = HamsterS()

hamster.board_left()
for i in range(3):
    hamster.board_forward()
hamster.board_right()
```

**우물 찾기 2**
```python
from roboid import *

hamster = HamsterS()

hamster.board_forward()
hamster.board_right()
for i in range(3):
    hamster.board_forward()
```

**우물 찾기 3**
```python
from roboid import *

hamster = HamsterS()

for i in range(2):
    hamster.board_forward()
    hamster.board_right()
    hamster.board_forward()
hamster.board_forward()
```

**우물 찾기 4**

hamster.board_right()

**우물 찾기 5**

## 03 앞 뒤 움직이기 (50–51p)

바퀴의 속도는 -100부터 100까지의 값을 가지며, 최대 속도에 대한 % 값이다. 양수 값이면 바퀴가 앞으로, 음수 값이면 뒤로 회전하고, 0이면 멈춘다. 왼쪽 바퀴와 오른쪽 바퀴의 속도를 같은 값으로 하면 앞/뒤로 직진한다.

**앞으로 이동**
```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(30, 30)  # 왼쪽 바퀴와 오른쪽 바퀴의 속도를 30으로 설정한다.
```

값을 하나만 입력하면 양쪽 바퀴의 속도를 같은 값으로 설정한다.
```python
hamster.wheels(30)  # 양쪽 바퀴의 속도를 30으로 설정한다.
```

**뒤로 이동** — 왼쪽·오른쪽 바퀴 속도를 같은 음수 값으로 설정
```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(-30, -30)  # 왼쪽 바퀴와 오른쪽 바퀴의 속도를 -30으로 설정한다.
```
```python
hamster.wheels(-30)  # 양쪽 바퀴의 속도를 -30으로 설정한다.
```

바퀴의 속도를 0부터 ±100까지 변경하면서 로봇이 이동하는 속도가 어떻게 달라지는지 관찰해본다.

## 04 제자리 돌기 (52p)

왼쪽 바퀴와 오른쪽 바퀴의 속도를 크기는 같게 하고 부호만 반대로 하면 제자리에서 회전한다. 로봇이 회전하는 중심점은 왼쪽 바퀴와 오른쪽 바퀴의 축을 연결하는 직선의 중심이다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(-30, 30)  # 왼쪽 바퀴의 속도를 -30, 오른쪽 바퀴의 속도를 30으로 설정한다.
```

## 05 한쪽 바퀴를 축으로 회전하기 (피봇 턴) (53p)

왼쪽 바퀴를 정지하고 오른쪽 바퀴에만 속도 값을 주면 왼쪽 바퀴를 중심으로 회전한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(0, 30)  # 왼쪽 바퀴의 속도를 0, 오른쪽 바퀴의 속도를 30으로 설정한다.
```

왼쪽 바퀴 또는 오른쪽 바퀴, 하나의 값만 설정하려면 `left_wheel()` 또는 `right_wheel()` 메소드를 사용해도 된다.

```python
hamster.left_wheel(30)  # 왼쪽 바퀴의 속도를 30으로 설정한다.
```
```python
hamster.right_wheel(30)  # 오른쪽 바퀴의 속도를 30으로 설정한다.
```

## 06 둥글게 회전하기 (라운드 턴) (54p)

왼쪽 바퀴와 오른쪽 바퀴의 속도 크기를 다르게 하면 원을 그리면서 회전한다. 두 바퀴 간의 속도 차이가 작을수록 큰 원을 그리면서 회전한다.

```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(20, 40)  # 왼쪽 바퀴의 속도를 20, 오른쪽 바퀴의 속도를 40으로 설정한다.
```

왼쪽 바퀴와 오른쪽 바퀴의 속도를 변경하면서 로봇이 회전하는 원의 크기가 어떻게 달라지는지 관찰해본다. 종이컵의 바깥을 돌 수 있도록 왼쪽 바퀴와 오른쪽 바퀴의 속도를 조정해본다.

## 07 종이컵 두고 돌기 (54p)

왼쪽 근접 센서 값에 따라 양쪽 바퀴의 속도를 바꾸며, 컵에 부딪히지 않고 컵 주위를 도는 활동. 난이도별로 3단계 예제가 있다.

**Beginner** — 센서 값이 10보다 크면 왼쪽 바퀴만, 작으면 오른쪽 바퀴만 돌려 급하게 방향을 튼다.
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() > 10:  # 왼쪽 근접 센서의 값이 10보다 커지면
        hamster.wheels(30, 0)  # 왼쪽 바퀴의 속도를 30, 오른쪽 바퀴의 속도를 0으로 설정한다.
    else:  # 왼쪽 근접 센서의 값이 10보다 작으면
        hamster.wheels(0, 30)  # 왼쪽 바퀴의 속도를 0, 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

**Intermediate** — 컵에서 멀 때는 양쪽 바퀴를 같은 속도로 직진, 가까울 때만 방향을 튼다.
```python
from roboid import *

hamster = HamsterS()

while True:
    if hamster.left_proximity() > 10:  # 왼쪽 근접 센서의 값이 10보다 커지면
        hamster.wheels(30, 30)  # 왼쪽 바퀴의 속도를 30, 오른쪽 바퀴의 속도를 30으로 설정한다.
    else:  # 왼쪽 근접 센서의 값이 10보다 작아지면
        hamster.wheels(0, 30)  # 왼쪽 바퀴의 속도를 0, 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

**Advanced** — 오른쪽 바퀴는 항상 30, 왼쪽 바퀴 속도는 센서 값에 비례하도록 계산해 부드럽게 감속·가속한다.
```python
from roboid import *

hamster = HamsterS()

while True:
    hamster.wheels(hamster.left_proximity()*(30/16), 30)
    # 왼쪽 바퀴의 속도는 왼쪽 센서의 값(16)과 기존 바퀴 속도(30)을 센서(16)로 나눈 값을 곱하여 설정한다.
    # 오른쪽 바퀴의 속도를 30으로 설정한다.
    wait(10)
```

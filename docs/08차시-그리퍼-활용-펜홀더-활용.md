# 8차시 — 그리퍼 활용 / 펜홀더 활용(햄스터S 용)

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 116–148쪽

전반부는 햄스터용 그리퍼(집게) 확장 모듈을 제어해 물건을 집고 나르는 활동, 후반부는 햄스터S용 펜홀더 확장 모듈로 도형·무늬를 그리는 활동이다. 소지한 악세서리에 맞는 활동을 선택한다.

---

## 그리퍼 활용 (116–131p)

### 01 연결 방법 (117p)

본 예제는 햄스터S를 이용한 것으로, 예제 활용을 위해 햄스터S와 햄스터용 그리퍼를 준비한다. 햄스터용 그리퍼는 햄스터와 햄스터S 모두 사용 가능하다. 햄스터에 그리퍼를 씌운 후 좌우측 선을 햄스터의 확장 포트(포트 A, 포트 B)에 연결해 사용 준비를 한다. 연결 방법은 로보메이션 유튜브 영상에서 확인할 수 있다.

### 02 관련 메소드 (118–121p)

그리퍼를 사용하려면 햄스터에서 제공하는 확장포트(A포트와 B포트)를 이용해야 한다.

| 메소드 | 설명 |
|---|---|
| `io_mode_a(mode)` | A포트의 입출력 모드를 설정한다. 그리퍼를 사용하려면 반드시 사용해야 하며, 파라미터는 디지털 출력 모드로 지정해야 한다. |
| `io_mode_b(mode)` | B포트의 입출력 모드를 설정한다. |
| `output_a(value)` | A포트에 대해 디지털 출력(H 또는 L)을 결정한다. 0을 넣으면 LOW, 1을 넣으면 HIGH로 출력된다. |
| `output_b(value)` | B포트에 대해 디지털 출력을 결정한다. |
| `open_gripper()` | 집게를 연다. (버전 1.4.0부터) |
| `close_gripper()` | 집게를 닫는다. (버전 1.4.0부터) |
| `release_gripper()` | 집게의 전원을 끄고 자유롭게 움직일 수 있도록 한다. (버전 1.4.0부터) |

`io_mode_a`의 `mode` 파라미터(정수):

| 입출력 모드 | 상수 값 | 설명 |
|---|---|---|
| `IO_MODE_ANALOG_INPUT` (아날로그 입력 모드) | 0 | 입력 전압을 8비트 ADC로 측정한다. 최대 입력 전압인 3.3V가 입력되면 255의 값을 가진다. |
| `IO_MODE_DIGITAL_INPUT` (디지털 입력 모드) | 1 | 입력 전압을 0과 1로 변환한다. 입력 전압이 1.6V 이상이면 1로 하고, 아니면 0으로 한다. |
| `IO_MODE_SERVO_OUTPUT` (아날로그 서보 출력 모드) | 8 | 외부 서보 제어용 PWM 신호를 출력한다. |
| `IO_MODE_PWM_OUTPUT` (PWM 출력 모드) | 9 | 듀티비(0~255 단계)에 따른 PWM 파형을 출력한다. |
| `IO_MODE_DIGITAL_OUTPUT` (디지털 출력 모드) | 10 | 디지털 값 LOW(0) 또는 HIGH(1)를 출력한다. |

```python
from roboid import *

hamster = Hamster()

# 포트 A의 입출력 모드를 아날로그 입력 모드로 설정한다.
hamster.io_mode_a(Hamster.IO_MODE_ANALOG_INPUT)
```

```python
from roboid import *

hamster = Hamster()

hamster.io_mode_a(Hamster.IO_MODE_PWM_OUTPUT)
# PWM 출력을 50으로 설정한다.
hamster.output_a(50)
```

`open_gripper` 또는 `close_gripper` 메소드로 집게를 열거나 닫으면, 상태를 유지하기 위해 집게의 전원이 계속 켜져 있다. 상태를 계속 유지할 필요가 없는 경우에는 배터리 소모를 줄이기 위해 `release_gripper`로 집게의 전원을 끄는 것이 좋다.

```python
from roboid import *

hamster = Hamster()

# 집게를 열고 전원을 끈다.
hamster.open_gripper()
hamster.release_gripper()
```

### 03 예제 (122–131p)

그리퍼를 제어하는 방법은 두 가지다. ① 직접 입/출력 제어모드를 통해 그리퍼를 제어하는 방법, ② 라이브러리 내 그리퍼 제어 관련 메소드를 이용하는 방법.

**열고 닫기 — 직접 입/출력 제어모드 활용** (1초에 한번씩 그리퍼를 열고 닫는 예제)
```python
from roboid import *

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

# 그리퍼 닫기 >(a:b)=(0:1)
# 그리퍼 열기 >(a:b)=(1:0)

# gripper 함수 > 1==OPEN, 0 == CLOSE
def gripper(state):
    if(state==1):  # 그리퍼 벌리기
        hamster.output_a(1)
        hamster.output_b(0)
    elif (state==0):  # 그리퍼 오므리기
        hamster.output_a(0)
        hamster.output_b(1)
    elif (state==-1):  # 그리퍼 동작 x
        hamster.output_a(0)
        hamster.output_b(0)

while True:
    gripper(1)
    wait(1000)
    gripper(0)
    wait(1000)
```

**열고 닫기 — 그리퍼 제어 관련 메소드 이용**
```python
from roboid import *

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

while True:
    hamster.open_gripper()
    wait(1000)
    hamster.close_gripper()
    wait(1000)
```

**키보드 입력을 통한 제어** — 1을 누르는 동안 그리퍼를 오므리고 2를 누르는 동안 그리퍼를 벌린다.
```python
from roboid import *
import keyboard

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

# 그리퍼 닫기 >(a:b)=(0:1)
# 그리퍼 열기 >(a:b)=(1:0)

# gripper 함수 > 1 == OPEN, 0 == CLOSE, -1 == OFF
def gripper(state):
    if(state==1):  # 그리퍼 벌리기
        hamster.output_a(1)
        hamster.output_b(0)
    elif (state==0):  # 그리퍼 오므리기
        hamster.output_a(0)
        hamster.output_b(1)
    elif (state==-1):  # 그리퍼 동작 x
        hamster.output_a(0)
        hamster.output_b(0)

while True:
    if keyboard.is_pressed("1"):  # 키보드에서 1이 눌리면
        gripper(0)
    elif keyboard.is_pressed("2"):  # 키보드에서 2이 눌리면
        gripper(1)
    elif keyboard.is_pressed("0"):  # 키보드에서 0이 눌리면
        gripper(-1)
    wait(20)  # 너무 빨리 반복하지 않도록 함
```

**센서 입력을 통한 제어(밝기 센서)** — 밝기 센서를 이용하여 물체가 바로 앞에 접근했을 때 그리퍼로 물체를 잡는다. 1을 누르면 오므리고 2를 누르면 벌리고 다른 것을 누르면 그리퍼가 꺼지도록 한다.
```python
from roboid import *

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

# 그리퍼 닫기 >(a:b)=(0:1)
# 그리퍼 열기 >(a:b)=(1:0)

# gripper 함수 > 1==OPEN, 0 == CLOSE
def gripper(state):
    if(state==1):  # 그리퍼 벌리기
        hamster.output_a(1)
        hamster.output_b(0)
    elif (state==0):  # 그리퍼 오므리기
        hamster.output_a(0)
        hamster.output_b(1)
    elif (state==-1):  # 그리퍼 동작 x
        hamster.output_a(0)
        hamster.output_b(0)

while True:
    print(hamster.light())
    if hamster.light() > 50:  # 밝기 센서의 값이 50 이상일 경우
        gripper(1)
    else:
        gripper(0)
    wait(20)  # 너무 빨리 반복하지 않도록함
```

**센서 입력을 통한 제어(근접 센서)** — 주행하다 근접 센서 값이 커지면 그리퍼로 해당 물체를 집는다.
```python
from roboid import *

hamster = HamsterS()
hamster.open_gripper()  # 그리퍼 열리게 설정
while True:
    hamster.wheels(30)  # 양쪽 바퀴의 속도를 30으로 설정한다.
    if hamster.left_proximity() > 50 and hamster.right_proximity() > 50:
        # 양쪽 근접 센서가 50보다 크면
        hamster.stop()  # 햄스터 정지
        wait(1000)  # 1초간 대기
        hamster.close_gripper()  # 그리퍼 닫음

    wait(20)  # 너무 빨리 동작하지 않도록 설정
```

**키보드 조작모드 활용** — 방향키로 이동, z/x/c 키로 그리퍼를 제어한다. 친구와 함께 컵을 지정된 위치에 두고 누가 더 먼저 컵을 들고 돌아오는지 대결해본다. (도안 A3 크기로 출력: https://robomation.net/?p=4465)
```python
from roboid import *
import keyboard

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

# 그리퍼 닫기 >(a:b)=(0:1)
# 그리퍼 열기 >(a:b)=(1:0)

while True:
    key = Keyboard.read()  # 키보드 이벤트를 얻는다.
    if keyboard.is_pressed("up"):  # 위 방향키를 눌렀을 경우
        hamster.wheels(30)
    elif keyboard.is_pressed("down"):  # 아래 방향키를 눌렀을 경우
        hamster.wheels(-30)
    elif keyboard.is_pressed("right"):  # 오른쪽 방향키를 눌렀을 경우
        hamster.wheels(30, -30)
    elif keyboard.is_pressed("left"):  # 왼쪽 방향키를 눌렀을 경우
        hamster.wheels(-30, 30)
    elif keyboard.is_pressed("z"):  # z키를 눌렀을 경우
        hamster.close_gripper()
    elif keyboard.is_pressed("x"):  # x키를 눌렀을 경우
        hamster.open_gripper()
    elif keyboard.is_pressed("c"):  # c키를 눌렀을 경우
        hamster.release_gripper()
    elif keyboard.is_pressed(" "):  # 스페이스 바를 눌렀을 경우
        hamster.wheels(0)
    wait(20)  # 너무 빨리 반복하지 않도록 한다.
```

**심부름꾼 햄스터!** — 햄스터가 집에서 출발하여 고기를 사서 돌아오는 심부름을 한다. 검정색 라인을 잘 따라가면 무시무시한 호랑이를 피할 수 있다. 왼쪽 아래의 고기 그림에 도착하면 햄스터를 잠시 멈추게 한 후 손으로 직접 고기를 넣어주고 뒤를 돌아 집으로 돌아가면 된다. 햄스터 로봇마다 모터 속도가 조금씩 차이 나기 때문에 왼쪽 또는 오른쪽으로 몇 초 동안 돌아야 정확히 뒤로 도는지 직접 테스트한 후 진행한다(힌트: 약 2초). (도안 A3 크기로 출력: https://robomation.net/?p=4465)
```python
from roboid import *

hamster = HamsterS()
hamster.io_mode_a(hamster.IO_MODE_DIGITAL_OUTPUT)
hamster.io_mode_b(hamster.IO_MODE_DIGITAL_OUTPUT)

# 그리퍼 닫기 >(a:b)=(0:1)
# 그리퍼 열기 >(a:b)=(1:0)

hamster.close_gripper()
while True:
    print(hamster.left_floor(), hamster.right_floor())  # 양쪽 바닥 센서 값 확인
    if (hamster.left_floor()>60 or hamster.right_floor()>60):  # 라인을 따라 갈 때(양쪽 바닥 센서가 60보다 클 때)
        hamster.line_tracer_mode(3)  # mode(3): 양쪽 모두 인식
        wait(20)  # 너무 빨리 반복하지 않도록 한다.

    elif (hamster.left_floor()<40 and hamster.right_floor()<40):  # 햄스터의 양쪽 센서 모두 검은 정지선을 밟을 때
        hamster.line_tracer_mode(3)
        hamster.stop()
        hamster.open_gripper()  # 그리퍼 열기
        hamster.release_gripper()
        wait(500)
        hamster.wheels(-22, 22)  # 반바퀴 회전
```

## 펜홀더 활용(햄스터S 용) (132–148p)

이하 모든 예제는 **햄스터S + 펜홀더**를 이용한다. 펜을 오른쪽 또는 왼쪽에 꽂고, `move_forward`, `pivot_right_pen`/`pivot_left_pen`, `right_pen_circle_left`/`left_pen_circle_right` 등의 메소드로 이동·회전하며 도형을 그린다.

### 01 초급 (133–136p)

**원 그리기** — 펜 위치는 오른쪽, 앞쪽 방향으로 원을 그린다. (반지름 3cm)
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽이며 햄스터가 왼쪽으로 돌며 원을 그립니다.
hamster.right_pen_circle_left(degree=360, radius=3)
```

**정삼각형 그리기** (한 변의 길이 3cm)
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽입니다.
for _ in range(3):
    hamster.move_forward(cm=3)  # 3cm만큼 앞으로 이동합니다.

    # 오른쪽 펜을 기준으로 제자리에서 120도 만큼 회전합니다.
    hamster.pivot_right_pen(degree=120)
```

**정사각형 그리기** (한 변의 길이 3cm)
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽입니다.
for _ in range(4):
    hamster.move_forward(cm=3)  # 3cm만큼 앞으로 이동합니다.

    # 오른쪽 펜을 기준으로 제자리에서 90도 만큼 회전합니다.
    hamster.pivot_right_pen(degree=90)
```

**정오각형 그리기** (한 변의 길이 2cm)
```python

# 펜 위치는 오른쪽입니다.

    # 오른쪽 펜을 기준으로 제자리에서 72도 만큼 회전합니다.

```

**정육각형 그리기** (한 변의 길이 2cm)

### 02 중급 (137–141p)

`.right_pen_circle_left`처럼 같은 메소드라도 반지름 부호에 따라 다른 방향으로 동작할 수 있다. 이를 유의해 주어진 방향대로 그림을 그릴 수 있도록 각도 부호를 유의하여 코드를 작성한다.

**원 3개 겹쳐 그리기** (원의 반지름 2cm)
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽입니다.
hamster.right_pen_circle_left(degree=360, radius=2)
# 오른쪽 펜을 기준으로 제자리에서 120도 만큼 회전합니다.
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
```

**원 5개 겹쳐 그리기** (원의 반지름 2cm)
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽입니다.
hamster.right_pen_circle_left(degree=360, radius=2)
# 오른쪽 펜을 기준으로 제자리에서 120도 만큼 회전합니다.
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
# 오른쪽 펜을 기준으로 제자리에서 -120도만큼 회전합니다.
hamster.right_pen_circle_left(degree=-120, radius=2)
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
hamster.pivot_right_pen(degree=120)
hamster.right_pen_circle_left(degree=360, radius=2)
```

**태극 무늬 그리기** (원의 반지름 5cm) — `.pivot_left_pen()`, `turn_right()` 같은 메소드를 활용해 더 정교한 동작을 만든다.
```python
from roboid import *

hamster = HamsterS()

# 펜 위치는 오른쪽입니다.
hamster.pivot_left_pen(degree=360, velocity=80)
# 오른쪽 펜을 기준으로 제자리에서 180도 만큼 회합니다.
hamster.turn_left(degree=180, velocity=40)
hamster.pivot_right_pen(degree=180, velocity=80)
hamster.turn_right(degree=-180, velocity=40)
```

**별 그리기(오각별)** (한 변의 길이 3cm)
```python
from roboid import *

hamster = HamsterS()

for _ in range(5):
    hamster.move_forward(cm=3)
    # 오른쪽 펜을 기준으로 제자리에서 -144도 만큼 회전합니다.
```

**꽃무늬 그리기(꽃잎 개수 입력)** — `.pivot_left_pen()` 메소드를 활용하여 더욱 정교한 동작을 한다. (꽃잎의 반지름 6cm)
```python
from roboid import *

hamster = HamsterS()

num = int(input("n: "))  # 정수 입력 받기.
internal = 180 * (num-2) / num  # 내각 계산하기.
external = 180 - internal  # 외각 계산하기.

for i in range(num):
    hamster.pivot_left_pen(external, 100)
    hamster.pivot_right_pen(-internal, 100)
    hamster.pivot_left_pen(external, 100)
    hamster.pivot_right_pen(-internal, 100)
    hamster.pivot_right_pen(external, 100)
```

**프랙탈 정다각형 그리기(변 길이 입력)** — Run 화면에 `n:`과 `l:`이 나타난다. 원하는 변의 길이를 정수로 입력하면 햄스터S가 도형을 그린다. (가장 큰 사각형의 길이 2cm, 코사인 법칙으로 빗변을 계산하는 재귀적 축소)
```python
from roboid import *
import math

hamster = HamsterS()
# 펜 위치는 오른쪽입니다.

n = int(input("n: "))  # 꼭지점 개수 설정하기.
l = int(input("l: "))  # 한 변의 길이 설정하기.
theta_rad = math.radians(180*(n-2)/n)

def fractal(length, angle):  # 빗변의 길이 정의하기 - 코사인법칙
    a = length / 2
    return math.sqrt(a**2 + a**2 - 2*a*a*math.cos(angle))

for i in range(n):
    for j in range(n):
        hamster.move_forward(cm=l)
        hamster.pivot_right_pen(degree=-360/n)
    hamster.move_forward(cm=l/2)
    hamster.pivot_right_pen(degree=-180/n)
    l = fractal(l, theta_rad)
```

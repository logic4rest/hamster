# 1차시 — 수업 준비

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 4–36쪽

햄스터 로봇의 하드웨어 구조를 이해하고, 파이썬 개발 환경(디바이스 드라이버, 파이썬, VS Code, 아나콘다, roboid 라이브러리)을 설치한 뒤 로봇과 컴퓨터를 블루투스로 연결하는 수업 준비 단계이다.

---

## 01 하드웨어 이해 (4–14p)

### 햄스터S 스펙

- 크기: 35 × 40 × 30mm, 무게 45g
- **근접 센서**(적외선 센서, 좌/우): 1~30cm, 1mm 정밀도, 햇빛 아래 동작 가능
- **밝기 센서**: 0~65,535룩스 감지
- **바닥 센서**(적외선 센서, 좌/우): 0~100단계 감지
- **3축 가속도 센서**: 2g/4g/8g/16g 범위 설정, 16비트 정밀도. 내부 온도 센서(섭씨 -41~+86.5도, 0.5도 정밀도)
- **모터**: 스테핑 모터 + 위성기어 감속기, 속도 제어 100단계, 최대 이동 속도 10cm/sec
- **LED**: 좌/우 LED
- **스피커**: 피에조 스피커
- **배터리**: 내장 리튬 배터리 3.7V, 200mA. 충전 약 60분, 연속 동작 평균 1시간, 대기 최대 12시간
- **전원 스위치**: 위로 올리면 ON, 아래로 내리면 OFF
- **USB 충전 포트**, 블루투스 연결 표시등, 충전 표시등
- **외부 확장 포트**: 보조 전원 포트(3.7V 리튬 폴리머 전지), 외부 입출력 포트 포트A·포트B(디지털 입력, 아날로그 입력, 디지털 출력, PWM 출력, 아날로그 서보 출력, 전압 입력, 시리얼 입출력)

### 충전

- 스마트폰용 충전기 또는 USB 케이블(마이크로 USB)로 충전 가능
- 충전 중에는 충전 표시등이 빨간색, 충전 완료 시 꺼짐
- 완전 충전 시 약 1시간 사용 가능. 전원을 끄고 충전하는 것이 더 좋음

### 표시등 상태

**블루투스 연결 표시등**

| 상태 | 의미 |
|---|---|
| 파란색으로 천천히 깜박임 | 블루투스 연결을 기다리는 상태 |
| 파란색으로 계속 켜져 있음 | 블루투스가 연결된 상태 |
| 파란색으로 빠르게 깜박임 | 데이터를 받고 있는 상태 |
| 표시등이 꺼짐 | 로봇의 전원이 꺼진 상태 |

**충전 표시등**

| 상태 | 의미 |
|---|---|
| 빨간색으로 켜져 있음 | 충전 중 |
| 표시등이 꺼짐 | 충전 완료 |
| 빨간색으로 깜박임 | 배터리가 거의 없음 — 반드시 충전 필요 |

### 햄스터 vs 햄스터S 주요 차이점

| 항목 | 햄스터 | 햄스터S |
|---|---|---|
| 모터 | DC 모터 | 마이크로 스테핑 모터 |
| LED | 7색 LED | 풀 컬러 LED (RGB 256×256×256 = 16,777,216가지 색상) |
| 확장 포트 | 디지털 입력, 아날로그 입력, 디지털 출력, PWM 출력, 서보 출력 | 위 기능 + 풀업/풀다운, 전압 입력, 시리얼 입출력 |

## 02 디바이스 드라이버 설치 (15–21p)

USB 동글을 컴퓨터 USB 포트에 꽂기 전에 디바이스 드라이버가 먼저 설치되어 있어야 한다. (단, 로봇 코딩 SW·로보이드 스튜디오를 설치하면 드라이버도 같이 설치되므로 별도 설치가 필요 없을 수도 있음)

1. [hamster.school](http://hamster.school/ko/) 접속
2. **다운로드** 클릭
3. **디바이스 드라이버 → [로보메이션]** 클릭
4. OS에 맞는 설치 파일 다운로드

**윈도우용 설치**
1. 내려받은 ZIP 파일 압축 풀기
2. exe 파일 실행 — 32비트: `CP210xVCPInstaller_x86.exe`, 64비트: `CP210xVCPInstaller_x64.exe`

**맥OS용 설치**
1. `SiLabsUSBDriverDisk.dmg` 디스크 이미지 파일 열기
2. `Silicon Labs VCP Driver.pkg` 파일 설치
3. 맥OS 10.13(하이 시에라)부터는 시스템 환경설정 → 보안 및 개인 정보 보호에서 사용자 허용 필요 (`Finder → 시스템 환경설정 → 보안 및 개인 정보 보호 → 허용`)

**리눅스용 설치**
1. `tar.gz` 파일 압축 풀기 (리눅스 버전에 따라 명령이 다름)
   ```
   tar xvfzp device-driver-linux.3.x.x.tar.gz
   tar xvfzp device-driver-linux.2.6.x.tar.gz
   ```
2. `drivers` 폴더가 생성되었는지 확인
3. 터미널에서 root 계정 로그인 & `drivers` 폴더로 이동
4. 쉘 스크립트 실행
   ```
   ./setup.sh
   ```

## 03 파이썬 설치 (22–24p)

1. [https://www.python.org](https://www.python.org) 접속 → **Downloads** 클릭
2. **Download Python 3.10.5** 클릭하여 설치
3. **Add Python 3.10 to PATH**를 체크한 후 **Install Now** 클릭
4. 검색창에 "IDLE"을 입력해 설치 여부 확인

---

## 03 VS Code 설치 (25–30p)

1. [https://code.visualstudio.com](https://code.visualstudio.com/) 접속 → **Download for Windows** 클릭
2. 본인 PC 운영체제에 맞는지 확인 후 "저장" 클릭
3. 설치 파일 실행 → "동의합니다" 선택 → "다음" 클릭
4. 원하는 추가 작업(바탕화면 바로가기, 탐색기 메뉴 등록, PATH 추가 등)을 체크한 후 "다음" 클릭
5. VS Code 실행 후 좌측 확장(Extensions) 아이콘 클릭
6. 검색창에 "Python" 입력 후 가장 상단의 "Python"(Microsoft) 확장을 설치(Install 버튼)
7. File → New File 클릭 후 "Text File" 또는 "Python File" 선택

---

## 03 아나콘다 설치 (31–32p)

1. [https://www.anaconda.com](https://www.anaconda.com) 접속 → Products에서 **Anaconda Distribution** 클릭
2. 페이지 아래로 내려가 본인 PC의 운영체제(Windows/MacOS/Linux)에 맞는 Installer를 클릭해 설치

> 아나콘다는 햄스터를 움직이는 데 필수는 아니며, 후속 차시의 인공지능(영상 처리, 티처블 머신 등) 실습에서 필요한 numpy 등 과학 계산 패키지를 미리 갖춘 환경을 구성하기 위해 설치한다.

---

## 04 라이브러리 설치 (33–34p)

1. VS Code에서 New File을 열어 예제 코드를 작성한다.
2. F5를 눌러 실행시킨 다음, 디버그 구성에서 **Python 파일**을 선택한다.
3. 실행 결과가 아래 Terminal 창에 출력된다.
4. 터미널 창에 다음을 입력하여 roboid 라이브러리를 설치한다.
   ```
   pip install -U roboid
   ```

## 05 로봇과 컴퓨터 연결 (35–36p)

1. **"USB to BLE Dongle"을 컴퓨터에 연결**
   - Dongle을 컴퓨터에 연결하면 파란색 불빛으로 천천히 깜박인다.
   - 표시등이 파란색이 아니라면:
     - 접촉 불량 → 동글을 살짝 눌러 접촉면을 넓혀본다
     - 포트 문제 → PC의 다른 포트에 연결해본다
     - 그래도 안 되면 Dongle 교체

2. **햄스터 로봇의 전원 스위치를 올린 후, 동글과 가까이 두기**
   - 전원을 켜고 동글과 가까이 두면 "삐" 소리가 나고, 햄스터 로봇과 동글 모두 파란색이 계속 켜지거나 빠르게 깜박인다.
   - 소리가 나지 않는다면 햄스터의 배터리가 충분한지 확인한다(배터리가 없으면 충전).

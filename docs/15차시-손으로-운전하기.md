# 15차시 — 손으로 운전하기

> 출처: [파이썬으로 배우는 햄스터와 인공지능 (ver240619)](파이썬으로-배우는-햄스터와-인공지능_ver240619.pdf) PDF 232–245쪽

`roboidai`의 `HandPose` 클래스로 카메라 영상 속 손을 검출해 손가락 관절 좌표를 얻고, 양손 손바닥 사이의 각도·거리로 햄스터를 조종한다.

## 01 영상처리 관련 클래스, 메소드 안내 (233–242p)

### 손 검출 — HandPose 클래스의 메소드

| 메소드 | 설명 |
|---|---|
| `HandPose()` | 손 검출 객체를 생성한다. 반환 값: 손 검출 객체 |
| `load_model(both_hands=False, threshold=0.5)` | 모델을 불러온다. `both_hands`: `True`면 양손, `False`면 한 손. `threshold`: 신뢰도가 이 값 이상인 경우에만 손으로 인정. 반환 값: `True`(성공), `False`(실패) |
| `detect(image)` | 손을 검출한다. `image`: 입력 영상(numpy.ndarray). 반환 값: `True`(성공), `False`(실패) |
| `draw_result(image, clone=False)` | 검출된 손을 표시한다. `clone`: `True`면 입력 영상을 복제한 영상에 표시(원본 유지), `False`면 복제 안 함. 반환 값: 검출된 손 결과가 표시된 영상 |
| `get_xy(hand, id='all', index=0)` | 손의 각 랜드마크의 x, y 좌표를 반환한다. `hand`: `'left'` 또는 `'right'`. `id`: 손가락 번호(`0`: 손목, `1`: 엄지, `2`: 검지, `3`: 중지, `4`: 약지, `5`: 새끼) 또는 `'all'`(모든 랜드마크), `'hand'`(손), `'palm'`(손바닥). `index`: 손가락의 경우 마디 번호(위에서 아래로 0, 1, 2, 3). 반환 값: `[x, y]` 리스트, `id`가 `'all'`이면 `[[x,y], [x,y], ..., [x,y]]` |
| `get_box(hand, id='all')` | 손 또는 손바닥의 사각형 영역을 반환한다. `id`: `'all'`(모든 영역), `'hand'`(손), `'palm'`(손바닥). 반환 값: `[x1, y1, x2, y2]` 리스트, `id`가 `'all'`이면 `[[x1,y1,x2,y2], ...]` |
| `get_width(hand, id='all')` | 손 또는 손바닥의 사각형 영역의 폭을 반환한다. |
| `get_height(hand, id='all')` | 손 또는 손바닥의 사각형 영역의 높이를 반환한다. |
| `get_area(hand, id='all')` | 손 또는 손바닥의 사각형 영역의 넓이를 반환한다(넓이 = 폭 × 높이). |
| `distance(pt1, pt2)` | 두 점 사이의 거리를 반환한다. `pt1`, `pt2`: `[x, y]`. 반환 값: 거리 값(픽셀) |
| `degree(pt1, pt2)` | `pt1`에서 `pt2`로 향하는 직선과 수평선 사이의 각도를 도(degree)로 반환한다. |
| `radian(pt1, pt2)` | `pt1`에서 `pt2`로 향하는 직선과 수평선 사이의 각도를 라디안으로 반환한다. |
| `get_feature(filter='all')` | 특징 벡터를 반환한다. `filter`: `'all'` 또는 튜플 `(손가락번호, ...)` 또는 리스트 `[손가락번호, ...]`. 반환 값: 특징 벡터(numpy.ndarray). 예: `get_feature()`, `get_feature('all')`, `get_feature((1, 3))`, `get_feature([2, 4, 5])` |

손가락 번호: 0-손목, 1-엄지, 2-검지, 3-중지, 4-약지, 5-새끼(엄지부터 새끼까지 시계 반대 방향으로 1~5번).

## 02 손으로 운전하기 (243–245p)

### 손 찾기

손을 찾는 예제를 실행해본다. 손을 감지하기 위해서는 `HandPose()`라는 클래스를 이용한다.

```python
import roboidai as ai

cam = ai.Camera('usb0', flip='h')
dt = ai.HandPose()  # 손 검출 클래스인 HandPose()를 dt로 저장한다.

dt.load_model()  # 손 검출 모델을 불러온다.

while True:
    image = cam.read()
    if dt.detect(image):  # 영상에서 손이 검출되면
        image = dt.draw_result(image)  # 검출될 손을 표시한다.

    cam.show(image)
    if cam.check_key() == 'esc': break
hamster.wheels(30, 30)  # 왼쪽 바퀴와 오른쪽 바퀴의 속도를 30으로 설정한다.
```

### 손으로 운전하기

두 손 위치의 각도 차이를 이용하여 햄스터를 주행하게 한다. 왼쪽/오른쪽 손바닥의 각도에 따라 왼쪽 바퀴는 "주행속도 − 각도×α", 오른쪽 바퀴는 "주행속도 + 각도×α"로 속도를 계산한다.

```python
import roboidai as ai
from roboid import *

hamster = HamsterS()
cam = ai.Camera('usb0', flip='h')
dt = ai.HandPose()
dt.load_model(both_hands=True)  # True로 양손 모두를 검출한다.

while True:
    image = cam.read()
    if dt.detect(image):  # 손이 검출되면
        left_xy = dt.get_xy('left', 'palm')  # 왼손바닥의 좌표와 오른손바닥의 좌표를 반환
        right_xy = dt.get_xy('right', 'palm')
        angle = dt.degree(left_xy, right_xy)  # 두 손바닥 간의 각도를 angle에 저장
        print(angle)
        if angle is not None:  # angle이 계산될 때, angle에 따라 햄스터 주행
            hamster.wheels(30-angle*0.5, 30+angle*0.5)
        else:  # angle이 없을 때, 정지
            hamster.stop()
        image = dt.draw_result(image)
    else:  # 손이 검출 안되면 정지
        hamster.stop()

    cam.show(image)
    if cam.check_key() == 'esc': break  # esc를 누르면 프로그램을 종료한다.
```

### 속도 + 방향으로 운전하기

두 손바닥 간의 거리(`dist`)로 속도를, 각도(`angle`)로 방향을 계산해 주행한다.

```python
import roboidai as ai
from roboid import *

hamster = HamsterS()
cam = ai.Camera('usb0', flip='h')
dt = ai.HandPose()
dt.load_model(both_hands=True)  # True로 양손 모두를 검출한다.

while True:
    image = cam.read()
    if dt.detect(image):  # 손이 검출되면
        left_xy = dt.get_xy('left', 'palm')  # 왼손바닥의 좌표와 오른손바닥의 좌표를 반환
        right_xy = dt.get_xy('right', 'palm')
        dist = dt.distance(left_xy, right_xy)  # 두 손바닥 간의 거리를 dist에 저장
        angle = dt.degree(left_xy, right_xy)  # 두 손바닥 간의 각도를 angle에 저장
        print(dist, angle)
        if angle is not None:  # angle이 계산될 때, angle에 따라 햄스터 주행
            hamster.wheels((dist/5-20.0)-angle*0.5, (dist/5-20.0)+angle*0.5)
        else:  # angle이 없을 때, 정지
            hamster.stop()
        image = dt.draw_result(image)
    else:  # 손이 검출 안되면 정지
        hamster.stop()

    cam.show(image)
    if cam.check_key() == 'esc': break  # esc를 누르면 프로그램을 종료한다.
```
